# TMS Design Brief v2 สำหรับ Claude Design

Nov 3, 2026 · @wei · แทนที่ฉบับ v1 (Oct 14, 2026)

TMS เป็นเครื่องมือที่ฝ่ายวางแผนรถและฝ่ายบัญชีใช้ทั้งวัน บุคลิกยังคงเป็น **ทางการ นิ่ง เชื่อถือได้** แต่รอบนี้เพิ่มคำว่า **พรีเมียม**: พื้นฟ้าเทาอ่อน การ์ดขาวมีเงาเบามาก ตัวเลขสำคัญใหญ่และมีสีตามความหมาย ไอคอน line-style ช่วยนำสายตา และทุกสถานะเป็นคำไทยบน badge สีทึบ ต้นแบบคือ **Alvys** (research ชี้ว่าเป็นต้นแบบหลัก: พื้นขาว/เทาอ่อน, accent สีเดียว, ตารางหนาแน่นแต่มีช่องไฟ, ⌘K) และ **LogisticsX** (3 ภาพ reference: KPI card, route chip, filter card, sidebar สว่างมี Favorites)

## 1. ทิศทาง และสิ่งที่เปลี่ยนจาก v1

**ผู้ใช้หลัก** — ฝ่ายวางแผนรถ (จอหนาแน่น ใช้ทั้งวัน), ฝ่ายบัญชี (ตัวเลขต้องเทียบได้), ผู้บริหาร (dashboard), ทีม Innovera (admin portal) — เดสก์ท็อป/แล็ปท็อป 1366–1920px

**บุคลิก 5 คำ:** ทางการ · แม่นยำ · สงบ · ชัดเจน · **พรีเมียม**

**อ้างอิงความรู้สึก:** Alvys, LogisticsX (ภาพ reference), Linear/Stripe Dashboard ในโทนสงบ — ไม่ใช่แอปเรียกรถ ไม่ใช่ admin template รุ่นเก่า sidebar ดำ

**ทำไมต้องทำ v2** — ผลจาก v1 "ถูก spec แต่แบน": brief สั่ง "ไม่มีเงา มุม 4px ไม่มีไอคอน" เข้มเกินไปจนทุกอย่างมีน้ำหนักเท่ากัน badge โชว์ชื่อ enum ภาษาอังกฤษ ไม่มี KPI card / status tab / route chip สีอำพันแทบไม่ปรากฏ และ sidebar navy ทึบกินสายตา

| หัวข้อ | v1 (แบน) | v2 (ทางการแต่พรีเมียม) |
| --- | --- | --- |
| Sidebar | พื้น navy `#0B1F3A` ทึบ ข้อความขาว | พื้นสว่าง `#F4F6FA` ข้อความ gray-900, เมนู active พื้น `primary-100` ข้อความ `primary-700`, มี Favorites + badge งานค้าง |
| Navy | ใช้เป็นพื้นผิวใหญ่ (sidebar/top bar) | ใช้เป็น accent: ลิงก์, ปุ่มรอง, ไอคอน active, ตัวเลข KPI "กำลังทำ", แถบซ้าย side panel |
| เงา | ไม่มี ยกเว้น modal | เงาเบามาก 1 ระดับบนการ์ด/KPI/filter card + ขอบบาง `gray-200` |
| มุมโค้ง | 4px ทุกอย่าง | การ์ด 10px, ปุ่ม/input 6px, badge 6px, chip 8px, avatar กลม |
| ไอคอน | ห้ามใช้ | Lucide line-style 16px (เมนู, badge, ปุ่ม, Actions column, empty state) |
| Badge | ข้อความ enum เช่น `ROUTE_PENDING`, พื้นอ่อน | ข้อความไทย "รอกำหนดเส้นทาง", พื้นสีทึบ + ไอคอน 12px |
| เหนือตาราง | ไม่มี | KPI card 3–4 ใบ, tab สถานะพร้อมตัวนับ, filter card, saved views |
| เส้นทางในตาราง | 2 คอลัมน์ ต้นทาง/ปลายทาง | route chip "กรุงเทพ → ชลบุรี" ในเซลล์เดียว |
| Accent อำพัน | เกือบไม่ปรากฏ | ปุ่มหลัก 1 ปุ่ม + KPI "รอตัดสินใจ" + badge รอคน + badge งานค้างใน sidebar |
| Hierarchy | ทุกอย่าง 14px/600 เท่ากัน | ตัวเลข KPI 28–32px/600, ชื่อหน้า 24px, label เล็ก gray-500 |
| Empty state | ข้อความ 1 บรรทัด + ปุ่ม | ไอคอน Lucide 1 ตัว 40px gray-300 + หัวข้อ + คำอธิบาย + ปุ่ม |
| Actions | ไม่กำหนด | คอลัมน์ขวาสุด ไอคอน ghost 2–3 ตัว + เมนู "⋯" |

**ยังต้องหลีกเลี่ยง** — gradient, เงาหนักหลายชั้น, สีสดหลายสีในหน้าเดียว, ภาพประกอบ/emoji, ภาษาไทย < 14px, สีเป็นตัวบอกสถานะอย่างเดียว, dark mode ในเฟสแรก, ที่อยู่ยาวจนแถวสูง (ตัด 1 บรรทัด + tooltip)

**กฎการใช้สี**

1. ปุ่ม accent 1 ปุ่มต่อหน้าจอ ("บันทึก", "ส่งเข้า KRS", "อนุมัติ", "สร้างใบวางบิล") ปุ่มอื่นเป็น navy outline หรือ ghost
2. ตัวเลข KPI ใช้สีตามความหมายของการ์ดนั้น (ดูภาพ LogisticsX: Overdue แดง, Paid เขียว, Outstanding navy) การ์ด "ทั้งหมด" ใช้ gray-900
3. แดงใช้กับ error/ไม่ตรง/ปุ่มทำลายเท่านั้น ตัวเลขติดลบใช้วงเล็บ + gray-900
4. กราฟ: `primary-500`, `primary-900`, `gray-500`, `accent-500` ไม่เกิน 4 series
5. เอกสารพิมพ์ขาวดำ ยกเว้นโลโก้และเส้นหัว `primary-900`
6. ในหนึ่งหน้าจอมี badge สีทึบได้หลายสี (เป็นข้อมูล) แต่พื้นผิวใหญ่ที่มีสีต้องไม่เกิน 1 (banner หรือ KPI ที่ highlight)

## 3. ตัวอักษร

คงเดิมจาก v1: UI ใช้ **IBM Plex Sans Thai**, ตัวเลข/รหัสใช้ **IBM Plex Mono**, เอกสารพิมพ์ใช้ **Sarabun** (Google Fonts ทั้งหมด)

| ฟอนต์ | ใช้กับ |
| --- | --- |
| IBM Plex Sans Thai | UI ทั้งหมด รวมตัวเลข KPI (tabular-nums) |
| IBM Plex Mono | เลข SO/DO/Invoice, ทะเบียนรถ, ยอดเงินในตาราง, JSON ใน log |
| Sarabun | DO, ใบวางบิล, ใบแจ้งหนี้, ใบงานประจำวัน, PDF |

**Type scale (UI)** — base 14px, line-height ไทย 1.6 ขึ้นไป

| ชื่อ | ขนาด / น้ำหนัก | ใช้กับ |
| --- | --- | --- |
| KPI number | 32px / 600, tabular-nums, lh 1.2 | ตัวเลขใหญ่ในการ์ด KPI (28px เมื่อมี 6 ใบ) |
| Page title | 24px / 600 | ชื่อหน้า บรรทัดเดียวกับปุ่ม action ขวา |
| H2 | 18px / 600 | หัวการ์ด, หัว side panel |
| H3 | 16px / 600 | หัว section ในฟอร์ม, หัว modal |
| Body | 14px / 400 | เซลล์ตาราง, ฟอร์ม, ข้อความทั่วไป |
| Body strong | 14px / 600 | ยอดรวม, ชื่อลูกค้าในแถว |
| Label | 13px / 500, gray-500 | label ใต้ KPI, หัวคอลัมน์ (ไทยตัวปกติ ไม่ ALL CAPS), label ฟอร์ม |
| Caption | 12px / 400 | timestamp, วันที่ใต้ badge (เช่น "25 ส.ค. 2569") — ห้ามใช้กับไทยที่ต้องอ่านจริงจัง |
| Mono | 13px / 400 | รหัสเอกสาร, ยอดเงิน, ทะเบียนรถ |

**เอกสารพิมพ์ A4** — Sarabun body 16pt, ตาราง 14pt, ชื่อเอกสาร 20pt, หมายเหตุ 12pt

**กฎ** — เงินชิดขวา 2 ทศนิยม คั่นหลักพัน (2,054,000.00) · วันที่หน้าจอ `14 ต.ค. 2569` (ค.ศ. ใน payload API, ตั้งค่าต่อ tenant) · ไม่ ALL CAPS ยกเว้นรหัสในโค้ด · ไม่ใช้ตัวเอียงกับไทย · หัวคอลัมน์ภาษาไทยตัวปกติ 13px/500 gray-500

## 4. Layout, spacing และ component

โครง sidebar สว่างซ้าย + content ขวา spacing ฐาน 4px พื้นหน้า `canvas #F4F6FA` การ์ดขาวขอบ `gray-200` 1px + เงา `0 1px 2px rgba(16,24,40,.04), 0 1px 3px rgba(16,24,40,.06)` (ระดับเดียว ใช้กับทุกการ์ด) dropdown/popover เงา `0 4px 12px rgba(16,24,40,.10)` modal/side panel `0 8px 24px rgba(16,24,40,.14)`

**โครงหน้า**

| ส่วน | ขนาด | รายละเอียด |
| --- | --- | --- |
| Sidebar | 256px (ย่อ 64px) | พื้น `canvas` ขอบขวา `gray-200`; บน: โลโก้ + ชื่อ tenant 14px/600; ช่องค้นหา `⌘K` สูง 36px พื้นขาว; section **Favorites** เป็น chip pill 28px (พื้น `primary-050`, ไอคอน 14px) เพิ่มด้วยปุ่ม "+"; กลุ่มเมนู label 11px/600 gray-500 letter-spacing .04em (หลัก / ปฏิบัติการ / บัญชี / ข้อมูลหลัก / ตั้งค่า); รายการเมนูสูง 40px ไอคอน 18px ช่องไฟ 12px; active พื้น `primary-100` ข้อความ `primary-700` มุม 8px; badge งานค้างทรง pill พื้น `accent-600` ขาว 11px/600 สูง 18px; ล่าง: สถานะเชื่อม KRS (จุด 8px เขียว/แดง + "KRS เชื่อมต่อ") และผู้ใช้ (avatar 32px ชื่อ + บทบาท) |
| Top bar | 56px | พื้นขาวขอบล่าง `gray-200`; ซ้าย breadcrumb; ขวา ปุ่ม ⌘K สั้น, แจ้งเตือน (ไอคอน bell + จุดแดง), ปุ่มสร้างเอกสาร "+" |
| Content | **เต็มความกว้างที่เหลือจาก sidebar (ไม่มี max-width)** padding 24px รองรับ 1366–2560px; ตาราง/การ์ดหลักสูงอย่างน้อยเต็ม viewport (pagination ติดก้นการ์ด, scroll ภายในตาราง); KPI grid auto-fit minmax(220px,1fr); จอ ≥1920 โชว์คอลัมน์เพิ่มแทนเว้นว่าง (แก้ 4 พ.ย. 69 จากเดิม max 1440) | ชื่อหน้า 24px ซ้าย + ปุ่ม action ขวา (primary 1 ปุ่ม + secondary + ไอคอน export) บรรทัดเดียวกัน → KPI row → filter card → ตาราง (ช่องว่างแนวตั้ง 20px) |
| Side panel | 480px เลื่อนจากขวา | พื้นขาว เงา modal แถบซ้าย 3px `primary-500`; หัว: เลขเอกสาร mono 16px + badge; tab ภายใน; ปุ่ม sticky ท้าย |
| Modal | 560px (approval) / 720px (preview payload) | มุม 12px, หัว H3, ปุ่มชิดขวา |

**Spacing scale:** 4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 — ระหว่างการ์ด 20px, ในการ์ด 20px, ตาราง 12px แนวตั้ง / 16px แนวนอน

**Component ที่ต้องมีใน design system**
