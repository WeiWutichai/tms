## กติกาของชุดนี้

- **บทบาท** (docs/04 J; spec/11 §4.1; สมมติฐาน LEG-1 ใน plan/07): tenant (บริษัทขนส่ง) = **ผู้ควบคุมข้อมูล** ของข้อมูลที่ tenant บันทึกในระบบ · Innovera = **ผู้ประมวลผลข้อมูล** · ยกเว้นข้อมูลบัญชีผู้ใช้/ความปลอดภัย/การสมัครและเรียกเก็บค่าบริการ ซึ่ง spec/11 §4.1 ให้ Innovera เป็นผู้ควบคุมเอง — **[ต้องให้ทนายตรวจ]** (LEG-1)
- อ้างมาตราของ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 เฉพาะที่ทีมมั่นใจ ส่วนที่ไม่แน่ใจเขียน **[ต้องให้ทนายตรวจ]** — ห้ามตัดป้ายนี้ออกจนกว่าทนายตอบ
- ผู้ให้บริการภายนอก (cloud, อีเมล, SMS, แผนที่, error tracking) ยังไม่เลือก = **[OPEN ST0-T01]**
- ระยะเก็บอ้างค่าที่อยู่ในโค้ด (ST9-T14); ข้อมูลที่โค้ดยังไม่มีการลบอัตโนมัติเขียนว่า "ยังไม่มีการลบอัตโนมัติ"
- เมื่อโค้ดเปลี่ยน (ตารางใหม่ที่มีข้อมูลบุคคล, ผู้ให้บริการใหม่, ระยะเก็บใหม่) ต้องแก้ 02-ropa.md ใน PR เดียวกัน; ทบทวนทั้งชุดทุก 12 เดือน (NFR-311)
