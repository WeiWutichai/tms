# 05a — คำตัดสิน PO รายการจุดต่างจาก `docs/` (D-68 → D-81)

> บันทึก 23 พ.ย. 2569 · ที่มา: หน้าตัดสินรายการ D-68 (artifact ของทีม) — PO แจ้ง **"ตอบครบแล้ว"** 23 พ.ย. 2569 **2 รอบ**: รอบแรกตอบครบ 99 ข้อ · รอบสอง **ยืนยันซ้ำ 41 ข้อ** ที่หน้ารุ่นแรกแสดงคอลัมน์เลื่อน (เครื่องหมาย `\|` ในข้อความที่ยกจาก docs ทำให้ตัวแยกตารางผิด) ครบ 41/41 — ตารางนี้คือ**ฉบับยืนยันซ้ำ** (ข้อที่เปลี่ยนจากรอบแรก: D68-03 คงตามที่ทำ → ถามนักบัญชี · D68-11 / D68-13 / D68-71 ไว้ทีหลัง → คงตามที่ทำ · D68-04 / D68-49 ยืนยันเดิม + เพิ่มหมายเหตุ)
> หมายเหตุหลายข้อระบุว่า "Claude ตัดสินแทน PO" = ผู้ช่วย Claude ร่างคำตัดสินให้ PO แล้ว **PO เป็นผู้ส่งคำตอบชุดนี้เองผ่านหน้า D-68** จึงถือเป็นคำตัดสินของ PO (`plan/05` D-81)
> คอลัมน์ "docs เขียนว่า" / "ที่ทำจริง" คัดมาจากรายการจุดต่างจาก docs 99 ข้อที่ทีมรวบรวมตาม D-68 (FACT + ข้อเสนอ ร่าง 23 พ.ย. 2569 · เลขบรรทัด docs = ไฟล์บน `origin/main` ก่อนแก้ตาม D-81) · "แถว spec/12 §3" = ลำดับแถวนับจากหัวตาราง §3 ณ `origin/main` `fc4c8d24` (ค้นด้วยชื่อแถวในวงเล็บ) — แถวนั้นมีหมายเหตุ "→ D-81 · D68-xx" ต่อท้ายแล้ว

## วิธีอ่าน / กติกา

- **คงตามที่ทำ — แก้ docs ให้ตรง:** ระบบคงไว้ · แก้ `docs/` ให้บรรยายสิ่งที่ทำ (ทุกจุดที่แก้ติดป้าย `(D-81 · D68-xx · 23 พ.ย. 2569)`) · ถ้า docs/01 กับ docs/04 ขัดกันเองและ PO เลือกฝั่งหนึ่ง แก้ฉบับที่แพ้ · เงื่อนไข/คำขอเพิ่มในหมายเหตุ PO ลงเป็นงานค้างใน `PROGRESS.md`
- **ปรับระบบตาม docs:** `docs/` คงเดิม · ระบบต้องแก้ตาม → งานค้างใน `PROGRESS.md` §งานที่เหลือ "งานแก้ระบบตามคำตัดสิน D-81"
- **ไว้ทีหลัง:** ไม่แก้ docs (เป้าหมายใน docs ยังอยู่) · ทำเมื่อถึงเงื่อนไขที่ระบุ
- **ถามคนนอก:** รอนักบัญชี / KRS — ระหว่างรอคงค่าเดิม · docs คงเดิม
