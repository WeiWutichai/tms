## 0. ขอบเขตและเกณฑ์ผ่าน

**เกณฑ์ผ่าน (ก) — FACT `docs/02` §7 + `plan/01` ST9-T21:** ผู้ใช้ KRS ทำครบสคริปต์เองได้ · **ปิดงวด 2 เดือนติดกัน** โดย MISMATCH ค้าง = 0 · มีลายเซ็นรับ
**FACT (#95-b):** รายงานปิดงวด `passed` = เดือนจบ + MISMATCH ค้าง 0 + เอกสารยังไม่ส่ง (`notSent`) 0 + ยังไม่ยืนยัน (`unverified`) 0
