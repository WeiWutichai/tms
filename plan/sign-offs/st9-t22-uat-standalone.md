## 2. ขั้นที่หน้าเว็บยังไม่มี — ทำผ่าน API (FACT 25 พ.ย. 2569 — ปรับหลังรอบ 0)

[DECISION — lead 24 พ.ย. เพื่อ UAT, ย้อนได้] ใช้ Open API ชุดเดียวกับ UI (หลัก API-first) สำหรับจุดที่หน้าเว็บยังไม่มีปุ่ม — บันทึกเป็นข้อสังเกต (ไม่ใช่ defect ของ UAT) แล้วส่งให้ Claude Design/PO ตามรายการใน `spec/12` §3:

| จุด | เหตุ (FACT) | ทำแทนอย่างไร |
|---|---|---|
| ปิดต้นทุนเที่ยวรถร่วม (COMPLETED → COSTED) | ไม่มีปุ่มในเว็บ — `POST /v1/trips/{id}/cost` | API ข้อ 2.2 |
| ~~สร้างใบสำคัญจ่ายรถร่วม (ติ๊กเที่ยว)~~ | **มีหน้าเว็บแล้ว** (#205): หน้า Settlement รถร่วม → "สร้างงวดใหม่" (ติ๊กเที่ยวจากคิวจ่าย + รายการหัก + เลขใบแจ้งหนี้ของผู้รับเหมา) | ใช้หน้าเว็บ · API ข้อ 2.3 ยังใช้ได้ |
| ~~เมนู "เที่ยวรถ" `/trips`, "ใบส่งของ (DO)" `/do`, "จ่ายงานรถร่วม" `/sub`~~ | **เปิดใช้แล้ว** (#198–#208) | ใช้เมนูได้ หรือเข้าทาง drawer จากกระดาน/หน้า SO เหมือนเดิม |

**2.1 สร้าง API key** — `admin` → ตั้งค่า → นักพัฒนา / Open API → สร้าง key (scope อย่างน้อย `trips:read trips:close settlements:read settlements:create prices.buy:read` — ไม่มี `prices.buy:read` = response ไม่แสดงยอดซื้อ/ยอดจ่าย (O-05) · ถ้าจะใช้ key ดูรายงานปิดงวดของ ST9-T21 ด้วยให้เพิ่ม `integrations:read`) → ยืนยัน 2FA → คัดลอก `tk_live_…` (แสดงครั้งเดียว)
```bash
export TMS=http://localhost:<API_PORT>/v1   # lane me = 5882 · worktree หลัก = 4410
export KEY=tk_live_...                       # จากข้อ 2.1
```
**2.2 ปิดต้นทุนเที่ยว** (หลัง POD ครบ) — หา id เที่ยว (`trp_…`) จาก drawer เที่ยวบนกระดาน หรือ `curl -s "$TMS/trips?limit=50" -H "Authorization: Bearer $KEY"`
```bash
curl -s -X POST "$TMS/trips/trp_XXXX/cost" -H "Authorization: Bearer $KEY"
```
**2.3 สร้างใบสำคัญจ่าย (ร่าง)** — ดูคิว: `curl -s "$TMS/settlements/queue" -H "Authorization: Bearer $KEY"` แล้ว
```bash
curl -s -X POST "$TMS/settlements" -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' -d '{
  "carrierId": "car_XXXX", "tripIds": ["trp_A","trp_B"],
  "deductions": [{"deductionType":"CASH_ADVANCE","description":"เงินเบิกล่วงหน้าค่าน้ำมัน","amount":"-2000.00","reference":"ADV-UAT-01"}],
  "carrierInvoiceNo": "SUB-INV-UAT-01", "carrierInvoiceDate": "2026-11-24" }'
```
ใบที่สร้างด้วย API key: ผู้สร้าง = ผู้ออก key (admin) → อนุมัติด้วย `approver` ได้ (SoD ผ่าน)
