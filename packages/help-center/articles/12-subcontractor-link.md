# ส่งงานให้รถร่วมผ่านลิงก์

ผู้รับเหมา (รถร่วม) ไม่ต้องมีบัญชี TMS — ตอบรับงาน แจ้งสถานะ และส่งหลักฐานผ่านลิงก์บนมือถือ ฟีเจอร์นี้อยู่ในแพ็กเกจที่มี "รถร่วม"

## ส่งข้อเสนอ

1. เปิดเที่ยวแล้วกด **ส่งต่อรถร่วม** จะเปิดแผง "จ่ายงานรถร่วม"
2. เลือก "ผู้รับเหมา" — ระบบเติม "ราคาซื้อ (฿ ต่อเที่ยว)" จาก rate card ฝั่งซื้อ และแสดงกำไร (ราคาขาย − ราคาซื้อ)
3. ถ้าไม่ได้เลือกรายที่ถูกที่สุด ต้องกรอก "เหตุผลที่เลือกรายนี้"
4. กด **ส่งข้อเสนอ** แล้ว **คัดลอกลิงก์** หรือ **ส่งผ่าน LINE** — ลิงก์มีอายุ 48 ชม.

## ฝั่งผู้รับเหมา

- เปิดลิงก์แล้วกด **รับงาน** กรอก "ทะเบียนรถ" "ชื่อคนขับ" "เบอร์คนขับ" แล้ว **ยืนยันรับงาน** — หรือกด **ปฏิเสธ** พร้อมเหตุผล
- ลิงก์ POD ใช้แจ้ง ถึงจุดรับ → ออกจากจุดรับ → ถึงจุดส่ง → ออกจากจุดส่ง และส่งรูป/ลายเซ็นผู้รับ (**ส่ง POD**)

## ติดตามข้อเสนอ

เมนู **ปฏิบัติการ → จ่ายงานรถร่วม** แยกแท็บ รอตอบ / รับงาน / ปฏิเสธ / หมดเวลา · ถ้าไม่ตอบภายในเวลาที่ตั้ง (ตั้งค่า → การจ่ายงานและติดตาม) ใช้ **ส่งต่อผู้รับเหมาถัดไป** หรือ **เปลี่ยนผู้รับเหมา**
