# วางบิลและออกใบแจ้งหนี้

TMS ออก **ใบแจ้งหนี้** และ **ใบวางบิล** · เอกสารภาษี (ใบกำกับภาษี ใบเสร็จรับเงิน) ออกจากโปรแกรมบัญชีของคุณ

![หน้าวางบิลและใบแจ้งหนี้](images/billing.png)

## สร้างใบแจ้งหนี้

1. เปิดเมนู **บัญชี → วางบิลและใบแจ้งหนี้**
2. ที่การ์ด "สร้างใบวางบิล": **เลือกลูกค้าและงวด** → **ติ๊ก DO** (ใบส่งของสถานะรอวางบิล) → **ตรวจ** → **ออกเอกสาร**
3. ขั้นนี้ได้ **ร่างใบแจ้งหนี้** ซึ่งยังไม่มีเลขที่ — ตรวจด้วย **พิมพ์ตัวอย่าง** หรือ **ยกเลิกร่าง** ถ้าไม่ต้องการ
4. เปิดร่างแล้วกด **ออกเอกสาร** ระบบออกเลขที่และล็อกเอกสาร — จากนั้นกด **พิมพ์ PDF**

> ผู้สร้างหรือผู้แก้ร่างใบแจ้งหนี้ ออกเอกสารใบนั้นเองไม่ได้ ต้องให้ผู้อื่นออก

## ใบวางบิล

1. ติ๊กใบแจ้งหนี้ที่ออกแล้วของลูกค้ารายเดียวกัน แล้วกด **สร้างใบวางบิล**
2. กรอก "วันนัดรับเช็ค / โอน" (ต้องระบุก่อนออกเอกสาร) แล้วกด **ออกเอกสาร**
3. เมื่อส่งแล้ว กด **บันทึกผู้รับวางบิล** และเมื่อได้เงิน กด **รับเช็ค / โอนแล้ว**

## ยกเลิกใบแจ้งหนี้

เอกสารที่ออกแล้วแก้ไม่ได้ ใช้ **ยกเลิกเอกสาร** พร้อมเหตุผล และเลือก **ออกฉบับใหม่แทน** ได้ — ยกเลิกไม่ได้ถ้ารับชำระแล้ว หรืออยู่ในใบวางบิลที่ออกแล้ว

## สถานะ

ร่าง → ออกแล้ว → ชำระบางส่วน → ชำระแล้ว (หรือ เกินกำหนด / ยกเลิก)

## สิทธิ์

สร้างร่าง: เจ้าของ ผู้ดูแลระบบ ผู้วางบิล บัญชี · ออกเอกสาร: เจ้าของ ผู้ดูแลระบบ ผู้จัดการ ผู้วางบิล บัญชี ผู้อนุมัติ · ยกเลิก: เจ้าของ ผู้ดูแลระบบ ผู้จัดการ
