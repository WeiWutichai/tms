# รับชำระจากลูกค้า

![หน้ารับชำระ](images/payments.png)

## บันทึกรับชำระ

1. เปิดเมนู **บัญชี → รับชำระ** เลือกใบแจ้งหนี้ แล้วกด **บันทึกรับชำระ**
2. เลือก "ประเภทการรับ" (เต็มจำนวน / บางส่วน) กรอก "จำนวนเงินที่รับ (฿)" "วิธีรับ" (โอนเงิน / เช็ค / เงินสด / หักกลบลบหนี้) "วันที่รับ" และ "เลขอ้างอิง / เลขที่เช็ค"
3. รับเป็นเช็ค: กรอก "ธนาคารของเช็ค" และ "วันที่หน้าเช็ค" ด้วย
4. ลูกค้าหักภาษี ณ ที่จ่าย: กรอก "ยอดที่ลูกค้าหัก (฿)" และ "เลขที่หนังสือรับรอง 50 ทวิ" ตามหนังสือที่ลูกค้าให้มา
5. มีค่าธรรมเนียมหรือส่วนต่างเล็กน้อย: กรอก "ค่าธรรมเนียมที่ลูกค้าหัก (฿)" หรือ "ส่วนต่างที่ยอมตัดยอด (฿)" พร้อมเหตุผล

> ส่วนต่างเกินวงเงินที่ตั้งไว้ ต้องให้ผู้จัดการบันทึก

## เช็ค

หลังเช็คเข้าบัญชี กด **เช็คผ่าน** · เช็คเด้ง กด **เช็คคืน** — สถานะเช็ค: รอเคลียร์ / เช็คผ่าน / เช็คคืน · บันทึกผิด ใช้ **กลับรายการ** (เจ้าของ ผู้ดูแลระบบ ผู้จัดการ)

## ติดตามลูกหนี้

แท็บ ค้างรับ / เกินกำหนด / ชำระบางส่วน และการ์ด **อายุลูกหนี้** · ส่งใบแจ้งเตือนด้วย **ส่งใบแจ้งเตือนชำระ**

## สิทธิ์

บันทึกรับชำระ: เจ้าของ ผู้ดูแลระบบ ผู้จัดการ บัญชี
