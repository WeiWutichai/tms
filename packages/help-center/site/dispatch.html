จัดรถและปล่อยเที่ยว

บนกระดานวางแผน

  1. เปิดเมนู ปฏิบัติการ → กระดานวางแผน เลือก วันนี้ / พรุ่งนี้ / 7 วัน
  2. ลาก SO จากรายการ SO รอจัด ทางซ้ายไปวางบนแถวรถ — ขอบเขียว = วางได้ · ขอบแดง = วางไม่ได้ · ระบบสร้างเที่ยวให้
  3. กด ส่งแผนให้คนขับ เพื่อส่งแผนทั้งวัน

ในหน้าเที่ยวรถ

  1. เปิด ปฏิบัติการ → เที่ยวรถ ลาก DO จาก DO รอเข้าเที่ยว ไปวางบนเที่ยว หรือบน เที่ยวใหม่
  2. เปิดเที่ยว ที่หัวข้อ "รถ / คนขับ" กด จัดรถ เลือกรถ (เรียงตามความเหมาะสม) คนขับ และคนขับสำรอง
  3. กด ปล่อยเที่ยว · พิมพ์ใบคุมรถด้วย พิมพ์ใบคุมรถ หรือ ส่งให้คนขับ
  4. ถ้าใช้รถร่วม กด ส่งต่อรถร่วม — ดู ลิงก์รถร่วม

คำเตือนและกฎห้ามจ่ายงาน

  • คำเตือน เช่น น้ำหนักเกิน · เอกสารรถหมดอายุ · ใบขับขี่หมดอายุ · เวลาชนกัน — ยืนยันจัดรถต่อได้ด้วย อนุมัติยกเว้น พร้อมเหตุผล (บันทึกในประวัติ)
  • ห้ามจ่ายงาน — ต้องแก้ข้อมูลให้ครบ หรือให้ผู้จัดการกด ยกเว้นกฎ พร้อมเหตุผล (ผู้วางแผนยกเว้นเองไม่ได้)

สิทธิ์

จัดรถ: เจ้าของ ผู้ดูแลระบบ ผู้จัดการ ผู้วางแผน ผู้จ่ายงาน · ปล่อยเที่ยว: เจ้าของ ผู้ดูแลระบบ ผู้จัดการ ผู้จ่ายงาน

สถานะเที่ยว

กำลังวางแผน → จัดรถแล้ว → ปล่อยรถแล้ว → กำลังวิ่ง → จบเที่ยว → ปิดต้นทุนแล้ว (รถร่วม: รอรถร่วมตอบ → … → จ่ายรถร่วมแล้ว) หรือ ยกเลิก
