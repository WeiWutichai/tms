รหัส error ของระบบ

เมื่อทำรายการไม่สำเร็จ หน้าจอจะแสดงข้อความด้านล่าง ระบบมีทั้งหมด 157 รหัส จัดกลุ่มตามประเภท — ค้นด้วยข้อความที่เห็นบนหน้าจอได้จากช่องค้นหาด้านบน

รายการนี้สร้างจากโค้ดของระบบโดยอัตโนมัติ ทุกครั้งที่ระบบเพิ่มรหัสใหม่ หน้านี้จะอัปเดตตาม · นักพัฒนาที่เชื่อมผ่าน Open API ดูรายละเอียดทางเทคนิคได้ในเอกสาร API หัวข้อ "รหัส error"

กลุ่ม: 400 คำขอไม่ถูกต้อง · 401 ต้องยืนยันตัวตน · 403 ไม่มีสิทธิ์ · 404 ไม่พบข้อมูล · 405 ไม่รองรับ · 409 ทำไม่ได้ในสถานะปัจจุบัน / ข้อมูลขัดกัน · 412 ข้อมูลถูกแก้โดยผู้อื่น · 413 ไฟล์ใหญ่เกิน · 422 ข้อมูลไม่ครบหรือไม่ถูกต้อง · 429 ทำรายการถี่เกินไป · 500 ระบบขัดข้อง · 503 ระบบไม่พร้อมชั่วคราว

400 — คำขอไม่ถูกต้อง

ทำอย่างไร: ลิงก์หรือข้อมูลที่ส่งไม่ถูกต้อง — ตรวจลิงก์ (เช่น ลิงก์คำเชิญหรือลิงก์ตั้งรหัสผ่านที่หมดอายุ) แล้วลองใหม่

รหัสข้อความบนหน้าจอ
bad_requestคำขอไม่ถูกต้อง
invalid_api_versionX-Api-Version ไม่ถูกต้อง (ต้องเป็นวันที่ YYYY-MM-DD)
invalid_grantการเข้าสู่ระบบหมดเวลา ลองใหม่อีกครั้ง
invalid_scopeขอ scope ที่ API key นี้ไม่มี
invitation_invalidลิงก์คำเชิญไม่ถูกต้อง หมดอายุ หรือใช้ไปแล้ว ขอให้ผู้ดูแลส่งคำเชิญใหม่
reset_link_invalidลิงก์ตั้งรหัสผ่านไม่ถูกต้อง หมดอายุ หรือใช้ไปแล้ว ขอลิงก์ใหม่อีกครั้ง

401 — ต้องยืนยันตัวตน

ทำอย่างไร: เข้าสู่ระบบใหม่ หรือกรอกรหัสยืนยันตัวตน 2 ชั้นตามที่หน้าจอบอก

รหัสข้อความบนหน้าจอ
invalid_clientclient_id หรือ client_secret ไม่ถูกต้อง
invalid_credentialsอีเมลหรือรหัสผ่านไม่ถูกต้อง
invalid_otpรหัสยืนยันไม่ถูกต้องหรือหมดอายุ
key_expiredAPI key หมดอายุแล้ว
key_revokedAPI key ถูกเพิกถอนแล้ว
mfa_enrollment_requiredบัญชีนี้ต้องตั้งการยืนยันตัวตน 2 ชั้นก่อนเข้าใช้งาน
mfa_expiredหมดเวลายืนยันตัวตน เข้าสู่ระบบใหม่อีกครั้ง
mfa_requiredกรอกรหัสยืนยันตัวตน 2 ชั้นจากแอป Authenticator
signup_session_invalidไม่พบการสมัครนี้หรือหมดอายุแล้ว เริ่มสมัครใหม่
unauthorizedต้องเข้าสู่ระบบ

403 — ไม่มีสิทธิ์

ทำอย่างไร: บัญชีของคุณยังไม่มีสิทธิ์ทำรายการนี้ หรือรายการนี้ต้องให้ผู้อื่นทำ (เช่น ผู้อนุมัติคนละคนกับผู้สร้าง) — ติดต่อผู้ดูแลบริษัทของคุณ

รหัสข้อความบนหน้าจอ
api_disabled_by_platformผู้ให้บริการปิดการใช้งาน API ของบริษัทนี้ชั่วคราว กรุณาติดต่อผู้ให้บริการ
bank_change_requires_userแก้หรือดูบัญชีธนาคารผู้รับเหมาผ่าน API key ไม่ได้ ต้องให้ผู้ใช้ทำในระบบ
bot_check_failedยืนยันว่าไม่ใช่บอทไม่สำเร็จ กรุณาลองใหม่อีกครั้ง
edit_lock_user_requiredการล็อกเพื่อแก้ไขใช้ได้เฉพาะผู้ใช้ในระบบ
erp_replace_self_approvalผู้ขอแทนที่เอกสารในระบบบัญชี (ผู้ออกใบใหม่ ผู้ยกเลิกใบเดิม หรือผู้สั่งส่งซ้ำ) อนุมัติเองไม่ได้ ต้องให้ผู้อนุมัติคนอื่น
feature_not_in_planแพ็กเกจปัจจุบันยังไม่มีฟีเจอร์นี้
forbiddenไม่มีสิทธิ์ทำรายการนี้
impersonation_read_onlyกำลังเข้าใช้งานแทนแบบอ่านอย่างเดียว — แก้ไขข้อมูลไม่ได้
invoice_self_finalizeผู้สร้างหรือผู้แก้ร่างใบแจ้งหนี้ ออกเอกสารใบนั้นเองไม่ได้ ต้องให้ผู้อื่นออก
ip_not_allowedIP นี้ไม่ได้รับอนุญาตให้ใช้ API key นี้
payment_difference_over_limitส่วนต่างเกินวงเงินที่ตั้งไว้ ต้องให้ผู้จัดการบันทึก
permission_deniedไม่มีสิทธิ์ทำรายการนี้
sandbox_onlyใช้ได้เฉพาะโหมด Sandbox (key tk_test_ หรือสลับเป็น Sandbox)
sandbox_unsupportedใช้ใน Sandbox ไม่ได้ (เชื่อมระบบภายนอกจริง)
self_approval_forbiddenยืนยันหรือปฏิเสธรายการที่ตัวเองบันทึกไม่ได้ ต้องให้ผู้อื่นตรวจ
settlement_self_approvalผู้เตรียมใบสำคัญจ่าย (สร้างใบ เพิ่มหรือนำรายการออก) อนุมัติใบนั้นไม่ได้ ต้องให้ผู้อนุมัติคนอื่น
settlement_self_paymentผู้อนุมัติใบสำคัญจ่าย บันทึกจ่ายใบนั้นเองไม่ได้ ต้องให้ผู้อื่นบันทึกจ่าย
step_up_requiredยืนยันตัวตน 2 ชั้นอีกครั้งก่อนทำรายการนี้
tenant_cancelledบัญชีบริษัทถูกยกเลิก ขอส่งออกข้อมูลได้จนถึงวันครบระยะเก็บข้อมูล
tenant_read_onlyบัญชีเป็นอ่านอย่างเดียว สร้างงานใหม่ไม่ได้ ดูและ export ได้
tenant_suspendedบัญชีบริษัทถูกระงับ ใช้ได้เฉพาะการชำระเงินและขอส่งออกข้อมูล
two_factor_enrolment_requiredบัญชีนี้ต้องตั้งการยืนยันตัวตน 2 ชั้นก่อนใช้งาน

404 — ไม่พบข้อมูล

ทำอย่างไร: ข้อมูลอาจถูกยกเลิกหรือไม่ได้อยู่ในบริษัทที่คุณเข้าใช้งาน

รหัสข้อความบนหน้าจอ
not_foundไม่พบข้อมูล

405 — ไม่รองรับ

ทำอย่างไร: ระบบไม่รองรับการทำรายการนี้

รหัสข้อความบนหน้าจอ
method_not_allowedไม่รองรับวิธีเรียกนี้

409 — ทำไม่ได้ในสถานะปัจจุบัน / ข้อมูลขัดกัน

ทำอย่างไร: สถานะของรายการไม่ตรงกับที่ต้องใช้ หรือมีข้อมูลซ้ำ — โหลดหน้าใหม่ ตรวจสถานะของรายการ แล้วทำตามข้อความบนหน้าจอ

รหัสข้อความบนหน้าจอ
account_existsอีเมลนี้มีบัญชีแล้ว เข้าสู่ระบบเพื่อเพิ่มบริษัทใหม่
alias_conflictรหัสหรือชื่อลูกค้าตามต้นทางนี้เคยจับคู่กับลูกค้ารายอื่นไว้แล้ว — ยืนยันการย้ายพร้อมเหตุผล
already_memberอีเมลนี้เป็นสมาชิกของบริษัทแล้ว
assignment_blockedรถหรือคนขับติดกฎห้ามจ่ายงาน — แก้เอกสารให้ครบ หรือให้ผู้จัดการยกเว้นพร้อมเหตุผล
assignment_warningsเที่ยวนี้มีคำเตือนที่ยังไม่ได้ยืนยัน — ยืนยันพร้อมเหตุผลก่อน
carrier_change_not_allowedเปลี่ยนผู้รับเหมาได้เฉพาะเที่ยวที่รอรถร่วมตอบ หรือรถร่วมรับงานแล้วแต่ยังไม่ปล่อยรถ
carrier_change_requires_cancelเปลี่ยนรถร่วมหรือสลับรถร่วม/รถบริษัทไม่ได้ — ยกเลิกการจ้างเดิมก่อน
channel_unavailableส่งทางช่องทางนี้ไม่ได้ตอนนี้ คัดลอกลิงก์ไปส่งเองได้
company_existsบริษัทนี้ใช้ TMS อยู่แล้ว ส่งคำขอเข้าร่วมบริษัทหรือติดต่อเรา
concurrent_updateมีการแก้ไขข้อมูลเดียวกันพร้อมกัน กรุณาลองใหม่อีกครั้ง
conflictข้อมูลขัดแย้งกับที่มีอยู่
connector_health_failedทดสอบการเชื่อมต่อไม่ผ่าน ตรวจค่าตั้งและ credential แล้วลองใหม่
connector_limit_reachedจำนวนการเชื่อมระบบบัญชีครบตามแพ็กเกจแล้ว
connector_scope_takenนิติบุคคลนี้เชื่อมระบบบัญชีอยู่แล้ว ยกเลิกการเชื่อมเดิมก่อน
delivery_order_on_tripใบส่งของนี้อยู่ในเที่ยวรถแล้ว — ถอดออกจากเที่ยวก่อน
do_already_draftedใบส่งของนี้อยู่ในใบแจ้งหนี้อื่นแล้ว
do_in_invoiceใบส่งของนี้อยู่ในใบแจ้งหนี้แล้ว — แก้ที่ใบแจ้งหนี้ หรือถอดออกจากร่างก่อน
do_releasedใบส่งของนี้ส่งบัญชีแล้ว — แก้จุดแวะ/ยอดส่งจริงไม่ได้ ให้ฝ่ายวางบิลย้อนการส่งบัญชีก่อน
document_email_pendingเอกสารนี้กำลังรอส่งถึงผู้รับเดิมอยู่ — รอสักครู่แล้วตรวจสถานะการส่ง
duplicateข้อมูลซ้ำกับที่มีอยู่
external_id_conflictเลขอ้างอิงต้นทางนี้ถูกใช้กับใบสั่งขนส่งจากช่องทางอื่นแล้ว
idempotency_in_progressคำขอเดียวกันกำลังประมวลผลอยู่
import_expiredผลตรวจไฟล์หมดอายุแล้ว (24 ชั่วโมง) อัปโหลดไฟล์ใหม่
import_has_errorsไฟล์มีแถวที่ตรวจไม่ผ่าน — แก้ไฟล์หรือเลือกนำเข้าเฉพาะแถวที่ผ่าน
in_useลบไม่ได้ เพราะมีเอกสารหรือข้อมูลอื่นอ้างถึงแล้ว — ใช้ "ปิดใช้" แทน
in_use_activeปิดใช้ไม่ได้ เพราะยังมีข้อมูลที่ใช้งานอยู่อ้างถึง
inbound_not_supportedระบบบัญชีนี้ไม่รองรับการส่งข้อมูลเข้ามาทาง webhook
invalid_state_transitionทำรายการนี้ไม่ได้ในสถานะปัจจุบัน
invoice_already_billedใบแจ้งหนี้นี้อยู่ในใบวางบิลอื่นแล้ว
invoice_has_paymentsใบแจ้งหนี้นี้รับชำระแล้ว ยกเลิกไม่ได้ — กลับรายการรับชำระก่อน
invoice_not_billableใบแจ้งหนี้นี้ยังไม่ออกหรือไม่มียอดค้าง ใส่ในใบวางบิลไม่ได้
invoice_not_finalizableยังออกเอกสารใบแจ้งหนี้นี้ไม่ได้
invoice_not_payableใบแจ้งหนี้นี้รับชำระไม่ได้ในสถานะปัจจุบัน
invoice_on_billing_noteใบแจ้งหนี้นี้อยู่ในใบวางบิลที่ออกแล้ว ยกเลิกไม่ได้ — ยกเลิกใบวางบิลก่อน
invoice_pdf_template_changedแม่แบบเอกสารเปลี่ยนหลังวันออก สร้าง PDF ของใบนี้ใหม่ไม่ได้ — ติดต่อผู้ดูแลระบบ
invoice_sent_to_customerใบแจ้งหนี้นี้ส่งลูกค้าแล้ว ยกเลิกไม่ได้
master_sync_failedดึงผังรหัสจากระบบบัญชีไม่สำเร็จ ตรวจการเชื่อมต่อแล้วลองใหม่
master_sync_not_supportedระบบบัญชีนี้ดึงผังรหัสอัตโนมัติไม่ได้ นำเข้าจากไฟล์แทน
not_ready_to_billใบส่งของนี้ยังไม่พร้อมวางบิล
offer_closedข้อเสนองานนี้ปิดแล้ว (ตอบไปแล้วหรือถูกยกเลิก)
offer_not_timed_outรถร่วมรายนี้ยังอยู่ในเวลาตอบรับ — ส่งรายถัดไปได้เมื่อครบเวลา
offer_requiredรถคันนี้เป็นรถร่วม — ต้องเสนองานให้รถร่วมก่อน แล้วจึงบันทึกการรับงาน
order_lock_releasedการแก้ไขของคุณถูกปลดล็อกโดยผู้อื่นแล้ว — โหลดใหม่ก่อนแก้ต่อ
order_locked_by_userใบสั่งขนส่งนี้กำลังถูกแก้ไขโดยผู้ใช้อื่น
order_locked_for_updateแก้ข้อมูลนี้ของใบสั่งขนส่งไม่ได้ในสถานะปัจจุบัน (วางแผน ออกรถ ปิดงาน หรือยกเลิกแล้ว)

order_on_tripใบสั่งขนส่งนี้มีใบส่งของอยู่ในเที่ยวรถ — ถอดออกจากเที่ยวก่อน
