# รหัส error ของระบบ

เมื่อทำรายการไม่สำเร็จ หน้าจอจะแสดงข้อความด้านล่าง ระบบมีทั้งหมด 139 รหัส จัดกลุ่มตามประเภท — ค้นด้วยข้อความที่เห็นบนหน้าจอได้จากช่องค้นหาด้านบน

> รายการนี้สร้างจากโค้ดของระบบโดยอัตโนมัติ ทุกครั้งที่ระบบเพิ่มรหัสใหม่ หน้านี้จะอัปเดตตาม · นักพัฒนาที่เชื่อมผ่าน Open API ดูรายละเอียดทางเทคนิคได้ในเอกสาร API หัวข้อ "รหัส error"

**กลุ่ม:** [400 คำขอไม่ถูกต้อง](#http-400) · [401 ต้องยืนยันตัวตน](#http-401) · [403 ไม่มีสิทธิ์](#http-403) · [404 ไม่พบข้อมูล](#http-404) · [405 ไม่รองรับ](#http-405) · [409 ทำไม่ได้ในสถานะปัจจุบัน / ข้อมูลขัดกัน](#http-409) · [412 ข้อมูลถูกแก้โดยผู้อื่น](#http-412) · [413 ไฟล์ใหญ่เกิน](#http-413) · [422 ข้อมูลไม่ครบหรือไม่ถูกต้อง](#http-422) · [429 ทำรายการถี่เกินไป](#http-429) · [500 ระบบขัดข้อง](#http-500) · [503 ระบบไม่พร้อมชั่วคราว](#http-503)

## 400 — คำขอไม่ถูกต้อง {#http-400}

**ทำอย่างไร:** ลิงก์หรือข้อมูลที่ส่งไม่ถูกต้อง — ตรวจลิงก์ (เช่น ลิงก์คำเชิญหรือลิงก์ตั้งรหัสผ่านที่หมดอายุ) แล้วลองใหม่

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `bad_request` | คำขอไม่ถูกต้อง |
| `invalid_api_version` | X-Api-Version ไม่ถูกต้อง (ต้องเป็นวันที่ YYYY-MM-DD) |
| `invalid_grant` | การเข้าสู่ระบบหมดเวลา ลองใหม่อีกครั้ง |
| `invalid_scope` | ขอ scope ที่ API key นี้ไม่มี |
| `invitation_invalid` | ลิงก์คำเชิญไม่ถูกต้อง หมดอายุ หรือใช้ไปแล้ว ขอให้ผู้ดูแลส่งคำเชิญใหม่ |
| `reset_link_invalid` | ลิงก์ตั้งรหัสผ่านไม่ถูกต้อง หมดอายุ หรือใช้ไปแล้ว ขอลิงก์ใหม่อีกครั้ง |

## 401 — ต้องยืนยันตัวตน {#http-401}

**ทำอย่างไร:** เข้าสู่ระบบใหม่ หรือกรอกรหัสยืนยันตัวตน 2 ชั้นตามที่หน้าจอบอก

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `invalid_client` | client_id หรือ client_secret ไม่ถูกต้อง |
| `invalid_credentials` | อีเมลหรือรหัสผ่านไม่ถูกต้อง |
| `invalid_otp` | รหัสยืนยันไม่ถูกต้องหรือหมดอายุ |
| `key_expired` | API key หมดอายุแล้ว |
| `key_revoked` | API key ถูกเพิกถอนแล้ว |
| `mfa_enrollment_required` | บัญชีนี้ต้องตั้งการยืนยันตัวตน 2 ชั้นก่อนเข้าใช้งาน |
| `mfa_expired` | หมดเวลายืนยันตัวตน เข้าสู่ระบบใหม่อีกครั้ง |
| `mfa_required` | กรอกรหัสยืนยันตัวตน 2 ชั้นจากแอป Authenticator |
| `unauthorized` | ต้องเข้าสู่ระบบ |

## 403 — ไม่มีสิทธิ์ {#http-403}

**ทำอย่างไร:** บัญชีของคุณยังไม่มีสิทธิ์ทำรายการนี้ หรือรายการนี้ต้องให้ผู้อื่นทำ (เช่น ผู้อนุมัติคนละคนกับผู้สร้าง) — ติดต่อผู้ดูแลบริษัทของคุณ

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `bank_change_requires_user` | แก้หรือดูบัญชีธนาคารผู้รับเหมาผ่าน API key ไม่ได้ ต้องให้ผู้ใช้ทำในระบบ |
| `bot_check_failed` | ยืนยันว่าไม่ใช่บอทไม่สำเร็จ กรุณาลองใหม่อีกครั้ง |
| `edit_lock_user_required` | การล็อกเพื่อแก้ไขใช้ได้เฉพาะผู้ใช้ในระบบ |
| `erp_replace_self_approval` | ผู้ขอแทนที่เอกสารในระบบบัญชี (ผู้ออกใบใหม่ ผู้ยกเลิกใบเดิม หรือผู้สั่งส่งซ้ำ) อนุมัติเองไม่ได้ ต้องให้ผู้อนุมัติคนอื่น |
| `feature_not_in_plan` | แพ็กเกจปัจจุบันยังไม่มีฟีเจอร์นี้ |
| `forbidden` | ไม่มีสิทธิ์ทำรายการนี้ |
| `impersonation_read_only` | กำลังเข้าใช้งานแทนแบบอ่านอย่างเดียว — แก้ไขข้อมูลไม่ได้ |
| `invoice_self_finalize` | ผู้สร้างหรือผู้แก้ร่างใบแจ้งหนี้ ออกเอกสารใบนั้นเองไม่ได้ ต้องให้ผู้อื่นออก |
| `ip_not_allowed` | IP นี้ไม่ได้รับอนุญาตให้ใช้ API key นี้ |
| `payment_difference_over_limit` | ส่วนต่างเกินวงเงินที่ตั้งไว้ ต้องให้ผู้จัดการบันทึก |
| `permission_denied` | ไม่มีสิทธิ์ทำรายการนี้ |
| `sandbox_only` | ใช้ได้เฉพาะโหมด Sandbox (key tk_test_ หรือสลับเป็น Sandbox) |
| `sandbox_unsupported` | ใช้ใน Sandbox ไม่ได้ (เชื่อมระบบภายนอกจริง) |
| `self_approval_forbidden` | ยืนยันหรือปฏิเสธรายการที่ตัวเองบันทึกไม่ได้ ต้องให้ผู้อื่นตรวจ |
| `settlement_self_approval` | ผู้เตรียมใบสำคัญจ่าย (สร้างใบ เพิ่มหรือนำรายการออก) อนุมัติใบนั้นไม่ได้ ต้องให้ผู้อนุมัติคนอื่น |
| `settlement_self_payment` | ผู้อนุมัติใบสำคัญจ่าย บันทึกจ่ายใบนั้นเองไม่ได้ ต้องให้ผู้อื่นบันทึกจ่าย |
| `step_up_required` | ยืนยันตัวตน 2 ชั้นอีกครั้งก่อนทำรายการนี้ |
| `two_factor_enrolment_required` | บัญชีนี้ต้องตั้งการยืนยันตัวตน 2 ชั้นก่อนใช้งาน |

## 404 — ไม่พบข้อมูล {#http-404}

**ทำอย่างไร:** ข้อมูลอาจถูกยกเลิกหรือไม่ได้อยู่ในบริษัทที่คุณเข้าใช้งาน

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `not_found` | ไม่พบข้อมูล |

## 405 — ไม่รองรับ {#http-405}

**ทำอย่างไร:** ระบบไม่รองรับการทำรายการนี้

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `method_not_allowed` | ไม่รองรับวิธีเรียกนี้ |

## 409 — ทำไม่ได้ในสถานะปัจจุบัน / ข้อมูลขัดกัน {#http-409}

**ทำอย่างไร:** สถานะของรายการไม่ตรงกับที่ต้องใช้ หรือมีข้อมูลซ้ำ — โหลดหน้าใหม่ ตรวจสถานะของรายการ แล้วทำตามข้อความบนหน้าจอ

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `alias_conflict` | รหัสหรือชื่อลูกค้าตามต้นทางนี้เคยจับคู่กับลูกค้ารายอื่นไว้แล้ว — ยืนยันการย้ายพร้อมเหตุผล |
| `already_member` | อีเมลนี้เป็นสมาชิกของบริษัทแล้ว |
| `assignment_blocked` | รถหรือคนขับติดกฎห้ามจ่ายงาน — แก้เอกสารให้ครบ หรือให้ผู้จัดการยกเว้นพร้อมเหตุผล |
| `assignment_warnings` | เที่ยวนี้มีคำเตือนที่ยังไม่ได้ยืนยัน — ยืนยันพร้อมเหตุผลก่อน |
| `carrier_change_not_allowed` | เปลี่ยนผู้รับเหมาได้เฉพาะเที่ยวที่รอรถร่วมตอบ หรือรถร่วมรับงานแล้วแต่ยังไม่ปล่อยรถ |
| `carrier_change_requires_cancel` | เปลี่ยนรถร่วมหรือสลับรถร่วม/รถบริษัทไม่ได้ — ยกเลิกการจ้างเดิมก่อน |
| `channel_unavailable` | ส่งทางช่องทางนี้ไม่ได้ตอนนี้ คัดลอกลิงก์ไปส่งเองได้ |
| `concurrent_update` | มีการแก้ไขข้อมูลเดียวกันพร้อมกัน กรุณาลองใหม่อีกครั้ง |
| `conflict` | ข้อมูลขัดแย้งกับที่มีอยู่ |
| `connector_health_failed` | ทดสอบการเชื่อมต่อไม่ผ่าน ตรวจค่าตั้งและ credential แล้วลองใหม่ |
| `connector_limit_reached` | จำนวนการเชื่อมระบบบัญชีครบตามแพ็กเกจแล้ว |
| `connector_scope_taken` | นิติบุคคลนี้เชื่อมระบบบัญชีอยู่แล้ว ยกเลิกการเชื่อมเดิมก่อน |
| `delivery_order_on_trip` | ใบส่งของนี้อยู่ในเที่ยวรถแล้ว — ถอดออกจากเที่ยวก่อน |
| `do_already_drafted` | ใบส่งของนี้อยู่ในใบแจ้งหนี้อื่นแล้ว |
| `do_in_invoice` | ใบส่งของนี้อยู่ในใบแจ้งหนี้แล้ว — แก้ที่ใบแจ้งหนี้ หรือถอดออกจากร่างก่อน |
| `do_released` | ใบส่งของนี้ส่งบัญชีแล้ว — แก้จุดแวะ/ยอดส่งจริงไม่ได้ ให้ฝ่ายวางบิลย้อนการส่งบัญชีก่อน |
| `document_email_pending` | เอกสารนี้กำลังรอส่งถึงผู้รับเดิมอยู่ — รอสักครู่แล้วตรวจสถานะการส่ง |
| `duplicate` | ข้อมูลซ้ำกับที่มีอยู่ |
| `external_id_conflict` | เลขอ้างอิงต้นทางนี้ถูกใช้กับใบสั่งขนส่งจากช่องทางอื่นแล้ว |
| `idempotency_in_progress` | คำขอเดียวกันกำลังประมวลผลอยู่ |
| `import_expired` | ผลตรวจไฟล์หมดอายุแล้ว (24 ชั่วโมง) อัปโหลดไฟล์ใหม่ |
| `import_has_errors` | ไฟล์มีแถวที่ตรวจไม่ผ่าน — แก้ไฟล์หรือเลือกนำเข้าเฉพาะแถวที่ผ่าน |
| `in_use` | ลบไม่ได้ เพราะมีเอกสารหรือข้อมูลอื่นอ้างถึงแล้ว — ใช้ "ปิดใช้" แทน |
| `in_use_active` | ปิดใช้ไม่ได้ เพราะยังมีข้อมูลที่ใช้งานอยู่อ้างถึง |
| `inbound_not_supported` | ระบบบัญชีนี้ไม่รองรับการส่งข้อมูลเข้ามาทาง webhook |
| `invalid_state_transition` | ทำรายการนี้ไม่ได้ในสถานะปัจจุบัน |
| `invoice_already_billed` | ใบแจ้งหนี้นี้อยู่ในใบวางบิลอื่นแล้ว |
| `invoice_has_payments` | ใบแจ้งหนี้นี้รับชำระแล้ว ยกเลิกไม่ได้ — กลับรายการรับชำระก่อน |
| `invoice_not_billable` | ใบแจ้งหนี้นี้ยังไม่ออกหรือไม่มียอดค้าง ใส่ในใบวางบิลไม่ได้ |
| `invoice_not_finalizable` | ยังออกเอกสารใบแจ้งหนี้นี้ไม่ได้ |
| `invoice_not_payable` | ใบแจ้งหนี้นี้รับชำระไม่ได้ในสถานะปัจจุบัน |
| `invoice_on_billing_note` | ใบแจ้งหนี้นี้อยู่ในใบวางบิลที่ออกแล้ว ยกเลิกไม่ได้ — ยกเลิกใบวางบิลก่อน |
| `invoice_pdf_template_changed` | แม่แบบเอกสารเปลี่ยนหลังวันออก สร้าง PDF ของใบนี้ใหม่ไม่ได้ — ติดต่อผู้ดูแลระบบ |
| `invoice_sent_to_customer` | ใบแจ้งหนี้นี้ส่งลูกค้าแล้ว ยกเลิกไม่ได้ |
| `master_sync_failed` | ดึงผังรหัสจากระบบบัญชีไม่สำเร็จ ตรวจการเชื่อมต่อแล้วลองใหม่ |
| `master_sync_not_supported` | ระบบบัญชีนี้ดึงผังรหัสอัตโนมัติไม่ได้ นำเข้าจากไฟล์แทน |
| `not_ready_to_bill` | ใบส่งของนี้ยังไม่พร้อมวางบิล |
| `offer_closed` | ข้อเสนองานนี้ปิดแล้ว (ตอบไปแล้วหรือถูกยกเลิก) |
| `offer_not_timed_out` | รถร่วมรายนี้ยังอยู่ในเวลาตอบรับ — ส่งรายถัดไปได้เมื่อครบเวลา |
| `offer_required` | รถคันนี้เป็นรถร่วม — ต้องเสนองานให้รถร่วมก่อน แล้วจึงบันทึกการรับงาน |
| `order_lock_released` | การแก้ไขของคุณถูกปลดล็อกโดยผู้อื่นแล้ว — โหลดใหม่ก่อนแก้ต่อ |
| `order_locked_by_user` | ใบสั่งขนส่งนี้กำลังถูกแก้ไขโดยผู้ใช้อื่น |
| `order_locked_for_update` | แก้ข้อมูลนี้ของใบสั่งขนส่งไม่ได้ในสถานะปัจจุบัน (วางแผน ออกรถ ปิดงาน หรือยกเลิกแล้ว) |
| `order_not_ready_for_delivery` | ยังสร้างใบส่งของจากใบสั่งขนส่งนี้ไม่ได้ (ร่าง ยกเลิก วางแผนแล้ว หรือยังจับคู่ลูกค้า/สถานที่ไม่ครบ) |
| `order_on_trip` | ใบสั่งขนส่งนี้มีใบส่งของอยู่ในเที่ยวรถ — ถอดออกจากเที่ยวก่อน |
| `order_source_change_pending` | ต้นทางแก้ใบสั่งขนส่งนี้หลังวางแผน — เลือกรับค่าต้นทางหรือใช้ค่า TMS ก่อนจัดลงเที่ยว |
| `payment_exceeds_outstanding` | ยอดตัดหนี้เกินยอดคงค้าง |
| `pod_exists` | ส่ง POD ของใบส่งของนี้แล้ว |
| `pod_not_allowed` | บันทึกหลักฐานส่งของใบส่งของนี้ไม่ได้ในสถานะปัจจุบัน |
| `queue_action_not_allowed` | ทำรายการนี้กับคำสั่งนี้ไม่ได้ (จัดการไปแล้ว หรือไม่ใช่รายการที่ล้มเหลว หรือต้องทำในระบบบัญชีเอง) |
| `sandbox_finalize_disabled` | โหมดทดสอบ (sandbox) ยังออกเลขใบแจ้งหนี้ไม่ได้ |
| `saved_view_limit` | บันทึกได้สูงสุด 50 มุมมองต่อหน้า |
| `seat_limit_reached` | จำนวนผู้ใช้ครบตามแพ็กเกจแล้ว |
| `secret_unreadable` | อ่านข้อมูลลับเดิมไม่ได้ (กุญแจเข้ารหัสเดิมถูกถอดออกแล้ว) — กรอกเลขใหม่แทน |
| `settlement_carrier_type_missing` | ข้อมูลรถร่วมในใบสำคัญจ่ายไม่มีประเภท (บุคคลธรรมดา/นิติบุคคล) คำนวณหัก ณ ที่จ่ายไม่ได้ — ยกเลิกใบแล้วสร้างใหม่ |
| `settlement_disputed` | มีรายการโต้แย้งที่ยังไม่เคลียร์ อนุมัติไม่ได้ — ยืนยันยอดเดิมพร้อมเหตุผล หรือเรียกใบกลับมาแก้รายการ |
| `settlement_empty` | ใบสำคัญจ่ายยังไม่มีรายการเที่ยว อนุมัติไม่ได้ |
| `settlement_line_resolved` | บริษัทยืนยันยอดของรายการนี้แล้ว ตอบรายการนี้ไม่ได้อีก |
| `settlement_net_negative` | ยอดสุทธิติดลบ อนุมัติไม่ได้ — นำรายการหักส่วนเกินออกแล้วยกไปงวดถัดไป |
| `settlement_review_required` | ต้องส่งให้รถร่วมตรวจก่อนอนุมัติ (ตั้งค่าบริษัท) |
| `sor_locked` | เปลี่ยนเจ้าของเอกสารไม่ได้ เพราะมีเอกสารส่งหรือรอส่งเข้าระบบบัญชีแล้ว — ยกเลิกการเชื่อมแล้วตั้งใหม่ |
| `source_change_not_pending` | การเปลี่ยนแปลงจากต้นทางชุดนี้ถูกตัดสินไปแล้ว หรือมีชุดใหม่มาแทน — โหลดใหม่ |
| `staff_deactivate_not_allowed` | ปิดบัญชีตัวเองหรือผู้ดูแลสูงสุดคนสุดท้ายไม่ได้ |
| `stop_already_closed` | จุดนี้ถูกปิดแล้ว — ส่ง POD ของ DO นี้ได้ |
| `stop_event_already_resolved` | เหตุการณ์นี้ถูกตัดสินไปแล้ว |
| `stop_event_duplicate` | clientEventId นี้ถูกใช้กับ event อื่นแล้ว |
| `stop_event_not_flagged` | เหตุการณ์นี้ไม่มีข้อขัดแย้งให้ตัดสิน |
| `stop_not_arrived` | ยังไม่ได้บันทึกถึงจุดนี้ |
| `stop_not_ready` | ปิดงานจุดก่อนหน้าก่อน |
| `stop_skipped` | จุดนี้ไม่มีใบส่งของแล้ว (นัดส่งใหม่ไปเที่ยวอื่น) — ไม่ต้องบันทึกที่จุดนี้ |
| `tax_document_owned_by_erp` | นิติบุคคลนี้ให้ระบบบัญชีเป็นผู้ออกใบกำกับภาษี — TMS ออกได้เฉพาะใบแจ้งหนี้/ใบวางบิล |
| `tenant_selection_required` | อีเมลนี้เป็นสมาชิกหลายบริษัท เลือกบริษัทที่ต้องการเข้า |
| `trip_cost_already_settled` | บรรทัดต้นทุนนี้อยู่ในใบสำคัญจ่ายอื่นแล้ว — จ่ายซ้ำไม่ได้ |
| `trip_cost_not_payable` | เที่ยวหรือบรรทัดต้นทุนนี้ยังไม่อยู่ในคิวจ่ายของรถร่วมรายนี้ (ต้องปิดต้นทุนแล้ว หลักฐานส่งครบตามเงื่อนไข และเป็นของรถร่วมรายนี้) |
| `trip_costing_unavailable` | ปิดต้นทุนเที่ยวถูกปิดใช้ชั่วคราวโดยผู้ดูแลระบบ |
| `trip_costs_incomplete` | ต้นทุนเที่ยวยังไม่ครบ — ยืนยัน/ปฏิเสธค่าใช้จ่ายหน้างานที่รอ ตรวจค่าจ้างรถร่วม และรายได้ของใบส่งของ (ใช้ปันต้นทุน) ก่อนปิดต้นทุน |
| `trip_empty` | เที่ยวนี้ยังไม่มีใบส่งของ |
| `trip_has_loaded_orders` | ยกเลิกเที่ยวไม่ได้ — มีใบส่งของที่รับของขึ้นรถหรือส่งแล้ว (ปิดเที่ยวบางส่วนแล้วเปิดเที่ยวใหม่แทน) |
| `trip_not_in_progress` | บันทึกสถานะหน้างานได้เฉพาะเที่ยวที่ปล่อยรถแล้วและยังไม่จบ |
| `trip_stops_open` | ยังมีจุดแวะที่ยังไม่จบ — ปิดเที่ยวได้เมื่อทุกจุดส่งสำเร็จ/ไม่สำเร็จ/ข้าม |
| `two_factor_not_enabled` | ยังไม่ได้ตั้งการยืนยันตัวตน 2 ชั้น |
| `webhook_limit_reached` | จำนวน webhook endpoint ครบตามแพ็กเกจแล้ว |

## 412 — ข้อมูลถูกแก้โดยผู้อื่น {#http-412}

**ทำอย่างไร:** มีคนแก้รายการเดียวกันก่อนคุณ — โหลดหน้าใหม่แล้วแก้อีกครั้ง

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `precondition_failed` | ข้อมูลถูกแก้ไขโดยผู้อื่นแล้ว กรุณาโหลดใหม่ |

## 413 — ไฟล์ใหญ่เกิน {#http-413}

**ทำอย่างไร:** ลดขนาดไฟล์หรือแบ่งไฟล์แล้วอัปโหลดใหม่

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `payload_too_large` | ไฟล์หรือข้อมูลมีขนาดใหญ่เกินกำหนด |

## 422 — ข้อมูลไม่ครบหรือไม่ถูกต้อง {#http-422}

**ทำอย่างไร:** แก้ช่องที่หน้าจอแสดงว่าผิด แล้วบันทึกอีกครั้ง

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `branch_unavailable` | นิติบุคคลออกบิลยังไม่มีสาขาที่ออกเอกสาร |
| `company_unavailable` | นิติบุคคลออกบิลไม่พบหรือปิดใช้อยู่ |
| `document_email_no_recipient` | ลูกค้ายังไม่มีอีเมลผู้ติดต่อ — เพิ่มอีเมลในข้อมูลลูกค้า หรือดาวน์โหลด PDF แล้วส่งเอง |
| `email_attachment_too_large` | ไฟล์ใหญ่เกินกว่าจะส่งทางอีเมล — ดาวน์โหลด PDF แล้วส่งเอง |
| `idempotency_mismatch` | Idempotency-Key นี้เคยใช้กับข้อมูลอื่น |
| `pod_incomplete` | หลักฐานการส่ง (POD) ยังไม่ครบตามที่ลูกค้ากำหนด |
| `routing_not_configured` | บริษัทมีหลายนิติบุคคลแต่ยังไม่ได้กำหนดนิติบุคคลออกบิล — ส่ง billingCompanyId (จาก GET /v1/companies) หรือตั้ง "ออกบิลในนาม" ที่ลูกค้า/ค่าตั้งต้นของบริษัท |
| `sor_fixed` | ระบบบัญชีนี้เป็นผู้ออกเอกสารภาษีเสมอ เปลี่ยนไม่ได้ |
| `sor_not_chosen` | เลือก "ใครออกเลขเอกสาร" ก่อนเปิดการส่งเอกสารเข้าระบบบัญชี |
| `stop_order_invalid` | ลำดับจุดไม่ถูกต้อง — จุดส่งของใบส่งของต้องอยู่หลังจุดรับของใบเดียวกัน |
| `validation_failed` | ข้อมูลไม่ถูกต้อง |
| `webhook_event_expired` | event เกิน 30 วันแล้ว ส่งซ้ำไม่ได้ |
| `webhook_event_not_subscribed` | endpoint นี้ไม่ได้สมัคร event ชนิดนี้ |
| `webhook_not_retryable` | ส่งซ้ำรายการนี้ไม่ได้ (event ทดสอบ) ใช้ "ส่ง event ทดสอบ" แทน |

## 429 — ทำรายการถี่เกินไป {#http-429}

**ทำอย่างไร:** รอสักครู่แล้วลองใหม่

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `account_locked` | ใส่รหัสผ่านผิดหลายครั้ง ลองใหม่อีกครั้งใน 15 นาที |
| `rate_limited` | เรียกถี่เกินไป |

## 500 — ระบบขัดข้อง {#http-500}

**ทำอย่างไร:** ลองใหม่อีกครั้ง ถ้ายังไม่ได้ ติดต่อฝ่ายช่วยเหลือพร้อมรหัส error และเวลาที่เกิด

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `internal_error` | ระบบขัดข้อง |
| `trip_cost_allocation_failed` | ปันต้นทุนเที่ยวลงใบส่งของไม่ลงตัว — ยังไม่ปิดต้นทุน กรุณาแจ้งผู้ดูแลระบบ |

## 503 — ระบบไม่พร้อมชั่วคราว {#http-503}

**ทำอย่างไร:** รอสักครู่แล้วลองใหม่ ถ้ายังไม่ได้ ติดต่อฝ่ายช่วยเหลือพร้อมรหัส error

| รหัส | ข้อความบนหน้าจอ |
|---|---|
| `pdf_render_timeout` | สร้าง PDF ไม่ทันเวลา กรุณาลองใหม่อีกครั้ง |
| `service_busy` | ระบบกำลังมีผู้ใช้งานมาก กรุณาลองใหม่อีกครั้ง |
