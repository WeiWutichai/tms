รับงาน (ใบสั่งขนส่ง)

งานขนส่งเริ่มจาก ใบสั่งขนส่ง (SO) เมื่อยืนยันแล้ว ระบบสร้าง ใบส่งของ (DO) ให้อัตโนมัติ ผู้สร้างและแก้ได้คือบทบาท เจ้าของ ผู้ดูแลระบบ ผู้จัดการ และผู้วางแผน

สร้างใบสั่งขนส่ง

  1. เปิดเมนู ปฏิบัติการ → ใบสั่งขนส่ง (SO) แล้วกด สร้าง SO (หรือ สร้างจากเทมเพลต / นำเข้า CSV)
  2. เลือก "ลูกค้า" "ประเภทรถที่ต้องการ" "วันรับของ" และกรอก "เลข PO ลูกค้า" (ถ้ามี)
  3. ที่ "จุดรับ–ส่ง" เลือกสถานที่และประเภทจุด (รับ / ส่ง / คืน) กด เพิ่มจุด และ เพิ่มสินค้า
  4. กด บันทึกร่าง หรือ บันทึกและยืนยัน — ราคาคำนวณจาก rate card ของลูกค้าเมื่อบันทึก

ใบค้าง

ถ้าระบบตรวจไม่ผ่าน ใบจะไปอยู่ที่ ใบค้าง พร้อมเหตุผล เช่น รอกำหนดเส้นทาง · ยังไม่จับคู่ลูกค้า · ยังไม่มีราคาขาย · ข้อมูลต้นทางไม่ครบ — แก้ด้วยปุ่ม จับคู่ลูกค้า เลือกสถานที่ กำหนดราคาเอง แล้วกด ตรวจอีกครั้ง

สถานะ

  • ใบสั่งขนส่ง: ร่าง → รับคำสั่งแล้ว → จัดรถแล้ว → ระหว่างส่ง → ส่งแล้ว → ปิดงาน (หรือ ค้าง / ส่งบางส่วน / ยกเลิก)
  • ใบส่งของ: รอจัดรถ → อยู่ในเที่ยว → ปล่อยรถแล้ว → รับของแล้ว → ส่งสำเร็จ → รอ POD → รอวางบิล → วางบิลแล้ว

ยกเลิกหรือแก้ไข

เมนูของแต่ละแถวมี แก้ไข คัดลอกเป็นใบใหม่ บันทึกเป็นเทมเพลต และ ยกเลิกเอกสาร (ต้องระบุเหตุผล) · ถ้ามีคนอื่นเปิดแก้อยู่ หน้าจอแสดง "กำลังแก้ไขโดย …" และดูได้อย่างเดียว
