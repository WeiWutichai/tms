GET /v1/planning/board

GET /v1/planning/board

scope: trips:read · operationId: Planning_board

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
datequerystringวันแรกของกระดาน (YYYY-MM-DD) — ไม่ส่ง = วันนี้ (เวลาไทย)
daysquerynumber ค่า: 1, 7จำนวนวัน: 1 = วันเดียว · 7 = 7 วัน

Responses

สถานะความหมายbody
200PlanningBoardDto
401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (trips:read) — permission_deniedProblemDto
422ข้อมูลไม่ถูกต้อง — errors[] รายช่อง — validation_failed, idempotency_mismatchProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto

curl -sS -X GET "$TMS_BASE_URL/v1/planning/board" \
  -H "Authorization: Bearer $TMS_API_KEY"
const { data, error } = await tms.GET('/v1/planning/board');

GET /v1/planning/eligibility

GET /v1/planning/eligibility

scope: trips:read · operationId: Planning_eligibility

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
orderIdquerystringSO (การ์ดใน "SO รอจัด") → ประเมินรถทุกคันบนกระดาน
vehicleIdquerystringรถ (แถวรถ) → ประเมิน SO รอจัดทุกใบ
tripIdquerystringเที่ยว ("ย้ายไปรถอื่น") → ประเมินรถทุกคันกับ DO ทั้งหมดของเที่ยว ในช่วงวิ่งของเที่ยว (รวมซ้อนเวลา)
datequerystringวันแรก (YYYY-MM-DD) ที่ตรวจเอกสารรถ/ใบขับขี่ — ไม่ส่ง = วันนี้ (เวลาไทย) · ไม่ใช้กับ tripId
daysquerynumber ค่า: 1, 7จำนวนวัน: 1 / 7

Responses

สถานะความหมายbody
200PlanningEligibilityDto
401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (trips:read) — permission_deniedProblemDto
404ไม่พบเที่ยว (รวมของบริษัทอื่น) — not_foundProblemDto
422ข้อมูลไม่ถูกต้อง — errors[] รายช่อง — validation_failed, idempotency_mismatchProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto

curl -sS -X GET "$TMS_BASE_URL/v1/planning/eligibility" \
