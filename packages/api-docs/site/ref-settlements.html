GET /v1/settlements/queue

scope: settlements:read · operationId: Settlements_list

เที่ยว COSTED ของรถร่วมที่ยังมีบรรทัดต้นทุนรอจ่าย (ค่าจ้าง CARRIER_FEE + ค่าใช้จ่ายหน้างานฝั่งซื้อที่ยืนยันแล้ว ของรถร่วมรายปัจจุบัน ที่ยังไม่อยู่ในใบสำคัญจ่าย) · รถร่วมที่ตั้ง "ไม่มี POD ไม่จ่าย" (requirePodToPay) → เที่ยวที่หลักฐานส่งยังไม่ครบไม่ขึ้นคิว · กรองรถร่วม (carrierId รับ ext:) / ช่วงวันที่เที่ยวจบ (เวลาไทย) / หลักฐานครบ · carriers = ยอดรวมต่อรถร่วมของทุกแถวที่ตรงตัวกรอง · ยอดเงิน (buy*) เห็นเมื่อมี prices.buy:read · ปิดต้นทุนเที่ยว (COMPLETED → COSTED) ปิดใช้ได้ด้วย kill switch (POST /trips/{id}/cost → 409 trip_costing_unavailable) — ระหว่างนั้นคิวว่าง

POST /v1/settlements

scope: settlements:create · operationId: Settlements_create

รถร่วม 1 ราย หลายเที่ยว: tripIds (ทุกบรรทัดที่รอจ่ายของเที่ยว) และ/หรือ tripCostIds (รายบรรทัด) — ต้องอยู่ในคิวจ่าย (GET /settlements/queue) ของรถร่วมรายนี้ มิฉะนั้น 409 trip_cost_not_payable · บรรทัดที่อยู่ในใบอื่นที่ยังใช้แล้ว → **409 trip_cost_already_settled** (กันจ่ายซ้ำ — unique ระดับ DB) · บรรทัดหัก (deductions) กรอกมือ ยอดติดลบ + เอกสารอ้างอิง · ยอดสุทธิ buyNetPayable = ยอดรวม − รายการหัก (ก่อนหัก ณ ที่จ่าย) · หัก ณ ที่จ่ายประมาณการ buyWhtAmount = ยอดก่อนหัก × อัตราของบรรทัด (whtRate ที่คัดลอกจากต้นทุน — ไม่มีธงใช้ค่าตั้งต้นของรถร่วม) ปัดครั้งเดียวต่อกลุ่มอัตรา + ขั้นต่ำ tax.whtMinimumAmount · buyNetAfterWht = ยอดจ่ายหลังหัก · whtEstimate แยกอัตรา + แบบ ภ.ง.ด.3/53 (ร่าง — ยังไม่ผ่านนักบัญชี) · งวดไม่ส่ง = ช่วงวันที่เที่ยวจบ (เวลาไทย) · audit settlement.created

BIL-136 · เฉพาะบรรทัดที่โต้แย้งค้าง ของใบ DISPUTED / ร่างที่เรียกกลับ / SENT_TO_CARRIER ที่มีโต้แย้งค้าง (อื่น ๆ → 409) · ปิดทุก dispute ก่อนหน้าของบรรทัดในรอบนี้ (รถร่วม + บัญชี) → สถานะรายการ APPROVED · ถ้าปิดข้อโต้แย้งของรถร่วม: รถร่วมตอบบรรทัดนี้ในรอบนี้ไม่ได้อีก (409 settlement_line_resolved) และเห็นเหตุผลนี้บนลิงก์ตรวจ · ปิดแค่ธงภายในของบัญชี: รถร่วมยังตอบได้และไม่เห็นเหตุผล · เคลียร์ครบ → DISPUTED กลับเป็น SENT_TO_CARRIER (อนุมัติได้) · ผู้เคลียร์นับเป็นผู้เตรียมใบ — อนุมัติใบนี้ไม่ได้ (separation of duties) · แก้ยอด = เรียกกลับแล้วนำบรรทัดออก/เพิ่มใหม่ · audit settlement.line_resolved

POST /v1/settlements/{id}/mark-paid

scope: settlements:pay · operationId: Settlements_markPaid

"จ่าย" + APPROVED → PAID · เฉพาะใบ APPROVED (ร่าง/รอตรวจ/โต้แย้ง/ยกเลิก/จ่ายแล้ว → 409 invalid_state_transition) · จ่ายเต็มยอดครั้งเดียว — ยอดที่จ่าย = buyNetAfterWht (ยอดสุทธิ − หัก ณ ที่จ่ายประมาณการที่ตรึงตอนอนุมัติ — ไม่เปลี่ยน) · paidDate (= วันที่หักภาษี) ตั้งแต่วันอนุมัติถึงวันนี้ (เวลาไทย) — ก่อนวันอนุมัติ → 422 before_approval · reference บังคับเมื่อ TRANSFER / CHEQUE · ใบที่ไม่ใช่ APPROVED (รวมจ่ายแล้ว/คำขอซ้ำพร้อมกัน) → 409 ก่อนตรวจ If-Match · เที่ยวที่บรรทัดต้นทุนจ่ายครบแล้ว COSTED → SETTLED (ไม่กลับเข้าคิวจ่าย) · ใบ PAID แก้ไม่ได้ · audit settlement.paid + webhook settlement.paid · ไฟล์โอนธนาคาร (bulk payment) = P1
