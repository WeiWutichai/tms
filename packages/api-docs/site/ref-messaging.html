POST /v1/messages/send-link

POST /v1/messages/send-link

scope: master:write หรือ trips:assign หรือ settlements:create · operationId: Messages_send

Request body SendLinkDto

ฟิลด์บังคับชนิดกฎคำอธิบายตัวอย่าง
channelใช่stringค่า: line, smsช่องทาง
urlใช่stringURL ลิงก์ที่ระบบออกให้ (เช่น url จาก POST /v1/carriers/{id}/upload-links) — ต้องเป็นลิงก์ที่ยังใช้ได้ของบริษัทนี้ ระบบเลือก template + สิทธิ์ตามชนิดลิงก์ · ผู้รับ = ช่องทางที่บันทึกไว้ของผู้รับเหมาเจ้าของลิงก์ (เบอร์มือถือ / LINE userId) — ระบุผู้รับเองไม่ได้

Responses

สถานะความหมายbody
202เข้าคิวส่งแล้ว (status queued) — worker ส่งจริงพร้อม retry; ติดตามผลที่ GET /v1/messages/{id} · ส่งไม่ได้/ล้ม ผู้ใช้ยังคัดลอก url ไปส่งเองได้เสมอMessageDeliveryDto
401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (master:write / trips:assign / settlements:create — มีตัวใดตัวหนึ่งก็พอ) — permission_deniedProblemDto
409channel_unavailable — ช่องทางปิดหรือยังไม่ตั้งค่า
422ข้อมูลไม่ถูกต้อง — errors[] รายช่อง (query/body) — validation_failedProblemDto
429เกินเพดานต่อบริษัท/ชั่วโมง หรือต่อผู้รับ/ชั่วโมงProblemDto

ตัวอย่าง

curl -sS -X POST "$TMS_BASE_URL/v1/messages/send-link" \
  -H "Authorization: Bearer $TMS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"channel":"line","url":"string"}'
const { data, error } = await tms.POST('/v1/messages/send-link', {
  body: {
    "channel": "line",
    "url": "string"
  },
});
