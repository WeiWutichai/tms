POST /v1/exports

scope: export:run · operationId: Exports_create

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
Idempotency-Keyheaderstring

Request body CreateExportDto

ฟิลด์บังคับชนิดกฎคำอธิบายตัวอย่าง
resourceใช่stringค่า: orders, customers, customer-sites, carriers, vehicles, vehicle-documents, drivers, vehicle-types, routes, products, service-items, rate-cards, reason-codes, unbilled-delivery-orders, receivables-aging, accounting-sales, accounting-receipts, accounting-settlementsorders
formatstringค่า: xlsx, csv.xlsx (แนะนำ — เลข 0 นำหน้าไม่หาย) หรือ.csv UTF-8 + BOM
filterobjectตัวกรองชุดเดียวกับ query ของ GET /v1/{resource} (ค่าเป็น string) — ตรวจกติกาเดียวกัน (field แปลก = 422) · limit/cursor/sort/fields/updatedAfter ไม่มีผล (ไฟล์มีทุกแถวที่ตรงตัวกรอง){"held":"true","holdReason":"RATE_MISSING"}

Responses

สถานะความหมายbody
202รับงานแล้ว — ต้องมี export:run + สิทธิ์อ่านของรายการนั้น (เช่น orders:read, master:read) · ไฟล์ไม่เกิน 100000 แถว · คอลัมน์ราคา/การเงินเฉพาะผู้มีสิทธิ์เห็นExportAcceptedDto
401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (export:run) — permission_deniedProblemDto
422ข้อมูลไม่ถูกต้อง — errors[] รายช่อง (query/body) — validation_failedProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto

ตัวอย่าง

curl -sS -X POST "$TMS_BASE_URL/v1/exports" \
  -H "Authorization: Bearer $TMS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"resource":"orders","filter":{"held":"true","holdReason":"RATE_MISSING"}}'
const { data, error } = await tms.POST('/v1/exports', {
  body: {
    "resource": "orders",
    "filter": {
      "held": "true",
      "holdReason": "RATE_MISSING"
    }
  },
});

GET /v1/accounting-exports/summary

scope: export:run · operationId: AccountingExport_summary

ชุดข้อมูล: sales ใบแจ้งหนี้ที่ออกแล้วและไม่ถูกยกเลิก (ISSUED / PARTIALLY_PAID / PAID / ADJUSTED — ชุดเดียวกับรายงานรายได้) ตามวันที่ออก · receipts การรับชำระที่ยังไม่กลับรายการ ตามวันที่รับ · settlements ใบสำคัญจ่ายรถร่วม PAID ตามวันที่จ่าย — แสดงเฉพาะชุดที่มีสิทธิ์อ่าน · ไฟล์: POST /v1/exports {resource, format: csv|xlsx, filter: {dateFrom, dateTo, template?}} → แถวเอกสาร 1 แถว + แถวรายการ (ยอดรวมอยู่เฉพาะแถวเอกสาร · CSV = UTF-8 BOM + CRLF เปิดใน Excel อ่านไทยได้)

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
dateFromqueryใช่stringวันแรกของช่วง (วันที่เอกสาร เวลาไทย) — ช่วงยาวสุด 366 วัน
dateToqueryใช่stringวันสุดท้ายของช่วง (รวมวันนี้)
templatequerystringรูปแบบไฟล์ (templates[].key จาก summary) — ไม่ส่ง = รูปแบบทั่วไป (layout กลาง: แถวเอกสาร + แถวรายการ)

Responses

401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (export:run) — permission_deniedProblemDto
422ข้อมูลไม่ถูกต้อง — errors[] รายช่อง — validation_failed, idempotency_mismatchProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto
