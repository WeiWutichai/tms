GET /v1/reports/revenue

scope: reports.finance:read · operationId: Reports_revenueReport

รายได้จากบรรทัดใบแจ้งหนี้ที่ออกเลขแล้ว (ISSUED / PARTIALLY_PAID / PAID / ADJUSTED — ไม่รวมร่างและใบที่ยกเลิก/void) ตามวันที่ออกใบ (เวลาไทย) ในช่วง fromMonth–toMonth จัดกลุ่มตาม groupBy (ลูกค้า / เส้นทาง / รถ / ประเภทรถ / นิติบุคคล / เดือน) · รายได้ = Σ ยอดบรรทัดหลังส่วนลด ก่อน VAT · Σ แถว = sellAmount รวม ทุกมิติ · บรรทัดที่ไม่ผูก DO / DO ที่ไม่มีเที่ยวหรือรถ อยู่แถว "ไม่ระบุ" (id: none) · sell* เห็นเมื่อมี prices.sell:read (ไม่มี = เห็นจำนวน) · ส่งออก: POST /v1/exports resource revenue (xlsx / csv / pdf) · แพ็กเกจต้องมีโมดูลรายงาน (report)

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
groupByquerystring ค่า: customer, route, vehicle, vehicleType, legalEntity, monthจัดกลุ่มตาม: customer ลูกค้า · route เส้นทาง (ต้นทาง – ปลายทางของ DO) · vehicle รถ · vehicleType ประเภทรถ · legalEntity นิติบุคคลผู้ออกใบ · month เดือนที่ออกใบ
fromMonthquerystringเดือนแรก (YYYY-MM ตามวันที่ออกใบ เวลาไทย) — ไม่ส่ง = เท่ากับ toMonth · ช่วงยาวสุด 24 เดือน
toMonthquerystringเดือนสุดท้าย (YYYY-MM รวมเดือนนี้) — ไม่ส่ง = เดือนปัจจุบัน (เวลาไทย)

401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (reports.finance:read) — permission_deniedProblemDto

DO ยังไม่วางบิลเกิน N วัน

GET /v1/reports/unbilled-delivery-orders

scope: reports.finance:read · operationId: Reports_unbilledDeliveryOrders

DO ที่ส่งถึงแล้ว (DELIVERED / POD_PENDING / UNBILLED) และยังไม่อยู่ในใบแจ้งหนี้ใด: includeStaleDrafts=true รวม DO ที่อยู่ในร่างใบแจ้งหนี้นานเกิน N วัน (วันนี้ − วันที่เข้าร่าง > N) พร้อม draftInvoice (id ร่าง + อายุ) ที่ วันนี้ − วันที่ส่งถึง > N (เวลาไทย) · วันที่ส่งถึง = เวลาบันทึกสถานะส่งถึงครั้งล่าสุด (ไม่มีประวัติ = วันที่ DO) · N = minDays หรือค่าตั้งองค์กร billing.unbilledAlertDays (ค่าเริ่ม 7) · เรียงส่งถึงเก่าสุดก่อน cursor (วันที่ส่งถึง, id) · มูลค่า = Σ บรรทัดรายได้ที่ยังใช้ (ก่อน VAT) — sell* เห็นเมื่อมี prices.sell:read · ส่งออก: POST /v1/exports resource unbilled-delivery-orders

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
minDaysqueryintegerส่งถึงแล้วเกินกี่วัน (วันนี้ − วันที่ส่งถึง > ค่านี้ เวลาไทย) — ไม่ส่ง = ค่าตั้งองค์กร billing.unbilledAlertDays (ค่าเริ่ม 7)
customerIdquerystringลูกค้ารายเดียว — id หรือ ext:{externalId}
includeStaleDraftsquerystring ค่า: true, falseรวม DO ที่อยู่ในร่างใบแจ้งหนี้ (billingStatus IN_DRAFT) นานเกิน N วัน (วันนี้ − วันที่ DO เข้าร่าง > N เวลาไทย — N ตัวเดียวกับ minDays) — แถวนั้นมี draftInvoice · ไม่ส่ง/false = เฉพาะ DO ที่ยังไม่อยู่ในใบใด (เดิม)
limitquerynumber
cursorquerystringค่า nextCursor จากหน้าก่อน (เรียงวันที่ส่งถึงเก่าสุดก่อน)
