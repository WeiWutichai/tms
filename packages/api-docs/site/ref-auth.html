POST /v1/oauth/token

POST /v1/oauth/token

scope: — · operationId: Auth_token

Request body TokenRequestDto

ฟิลด์บังคับชนิดกฎคำอธิบายตัวอย่าง
grantTypeใช่stringค่า: authorization_code, refresh_token, client_credentialsclient_credentials = client ภายนอกด้วย API key: clientId key_… + clientSecret tk_live_… (หรือ HTTP Basic) → JWT RS256 1 ชม.
codestringgrantType=authorization_code
codeVerifierstringgrantType=authorization_code (PKCE)
clientIdstringgrantType=client_credentials — id ของ key (key_…) หรือ prefix ที่แสดงในหน้าจอ · หรือส่งใน Authorization: Basictk_live_8f3a
clientSecretstring (password)grantType=client_credentials — API key เต็ม (tk_live_…)
scopestringgrantType=client_credentials — scope ที่ขอ (คั่นด้วยช่องว่าง ⊆ scope ของ key; ไม่ส่ง = ทั้งหมด)orders:read orders:write

Responses

สถานะความหมายbody
200authorization_code / refresh_token: ตั้ง refresh token ใน cookie httpOnly tms_rt · client_credentials: ไม่มี refresh token (error: 401 invalid_client / key_revoked / key_expired, 400 invalid_scope, 403 ip_not_allowed)TokenDto
429rate_limited — เกิน 120 ครั้ง/นาที ต่อ IP หรือ 30 ครั้ง/นาที ต่อ client id (client_credentials) มี header Retry-AfterProblemDto

ตัวอย่าง

curl -sS -X POST "$TMS_BASE_URL/v1/oauth/token" \
  -H "Authorization: Bearer $TMS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"grantType":"authorization_code","clientId":"tk_live_8f3a","scope":"orders:read orders:write"}'
const { data, error } = await tms.POST('/v1/oauth/token', {
  body: {
    "grantType": "authorization_code",
    "clientId": "tk_live_8f3a",
    "scope": "orders:read orders:write"
  },
});
