POST /v1/test/events/trigger

POST /v1/test/events/trigger

scope: settings:read · operationId: TestEvents_trigger

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
X-Tms-Modeheaderstring ค่า: live, testเฉพาะผู้ใช้ที่ login (UI): test = จัดการข้อมูลของ Sandbox ของบริษัท (key tk_test_, webhook ของ sandbox) · ไม่ส่ง = live · API key ไม่ใช้ header นี้ (โหมดตาม key)

Request body TriggerTestEventDto

ฟิลด์บังคับชนิดกฎคำอธิบายตัวอย่าง
typeใช่stringค่า: order.created, order.updated, order.held, order.released, order.cancelled, trip.assigned, trip.dispatched, trip.started, trip.completed, trip.cancelled, stop.arrived, stop.departed, stop.completed, stop.failed, delivery_order.status_changed, pod.captured, invoice.finalized, invoice.voided, payment.recorded, payment.reversed, settlement.approved, connector.health_changed, job.completedevent สาธารณะที่ยิงได้ในเฟสนี้ (phase: active ใน GET /v1/webhooks/event-types) — data.object = ตัวอย่างตาม schema ของ event (ข้อมูลสมมติ)order.created

Responses

สถานะความหมายbody
200ยิงแล้วและส่งไป endpoint ของ sandbox ที่สมัคร event นี้ทันที (รอผลต่อ endpoint ≤ 10 วิ — ล้มตามรอบ retry ปกติ; ดูทุกครั้งที่ GET /v1/webhook-deliveries?eventId=) · นอก sandbox → 403 sandbox_only · event ที่ไม่อยู่ในทะเบียน/ยังไม่เปิด (pending) → 422TriggerTestEventResultDto
401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (settings:read) — permission_deniedProblemDto
422ข้อมูลไม่ถูกต้อง — errors[] รายช่อง (query/body) — validation_failedProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto

ตัวอย่าง

curl -sS -X POST "$TMS_BASE_URL/v1/test/events/trigger" \
  -H "Authorization: Bearer $TMS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"type":"order.created"}'
const { data, error } = await tms.POST('/v1/test/events/trigger', {
  body: {
    "type": "order.created"
  },
});
