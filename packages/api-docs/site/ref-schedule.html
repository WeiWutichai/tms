Parameters

toqueryใช่string (date)วันสุดท้าย (รวม) — ช่วงไม่เกิน 62 วัน

Idempotency-Keyheaderstring

Request body CreateScheduleEntryDto

ฟิลด์บังคับชนิดกฎคำอธิบายตัวอย่าง
kindใช่stringค่า: LEAVE, NOTELEAVE = วันลาคนขับ (ต้องมี driverId) · NOTE = โน้ตรายวันของคนขับหรือรถ (อย่างใดอย่างหนึ่ง)
driverIdstringdrv_…
vehicleIdstringเฉพาะ NOTEveh_…
startsOnใช่string (date)วันแรก (วันไทย)2026-11-18

noteใช่stringยาว ≤ 500 · ยาว ≥ 1เหตุผลการลา / ข้อความโน้ตลาป่วย

422ข้อมูลไม่ถูกต้อง — errors[] รายช่อง — validation_failed, idempotency_mismatchProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto
