POST /v1/documents

POST /v1/documents

scope: documents:write · operationId: Documents_create

Request body CreateDocumentDto

ฟิลด์บังคับชนิดกฎคำอธิบายตัวอย่าง
kindใช่stringค่า: POD_PHOTO, POD_SIGNATURE, POD_FILE, SIGNATURE, LOGO, PDF, VEHICLE_DOC, RECEIPT, WHT_CERT, CONTRACT, IMPORT, OTHER
mimeใช่stringค่า: application/pdf, image/png, image/jpeg, image/webp, application/vnd.openxmlformats-officedocument.spreadsheetml.sheet, text/csvชนิดที่จะอัปโหลด — server ตรวจกับเนื้อไฟล์จริง
bytesใช่numberขนาดไฟล์ (byte) ไม่เกิน 10485760182044
filenamestringpod-SO-2611-0001.jpg
clientDocumentIdstringid ฝั่ง client (อุปกรณ์) — ส่งซ้ำได้ ไม่สร้างแถวใหม่
entityTypestringtrip_stop

Responses

สถานะความหมายbody
201DocumentDto
401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (documents:write) — permission_deniedProblemDto
409clientDocumentId นี้ถูกใช้แล้ว (คนอื่น/ชนิดอื่น/ขนาดอื่น) — duplicateProblemDto
422ชนิด/ขนาดไม่ถูกต้อง — errors[] รายช่อง — validation_failedProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto

ตัวอย่าง

curl -sS -X POST "$TMS_BASE_URL/v1/documents" \
  -H "Authorization: Bearer $TMS_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"kind":"POD_PHOTO","mime":"application/pdf","bytes":182044,"filename":"pod-SO-2611-0001.jpg","entityType":"trip_stop"}'
const { data, error } = await tms.POST('/v1/documents', {
  body: {
    "kind": "POD_PHOTO",
    "mime": "application/pdf",
    "bytes": 182044,
    "filename": "pod-SO-2611-0001.jpg",
    "entityType": "trip_stop"
  },
});

GET /v1/documents/{id}

GET /v1/documents/{id}

scope: documents:read · operationId: Documents_get

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
idpathใช่string

Responses

สถานะความหมายbody
200ไฟล์ส่งออก (EXPORT) เห็นเฉพาะผู้สั่ง · ไฟล์นำเข้า (IMPORT) เห็นเฉพาะผู้อัปโหลด (API key เห็นเฉพาะไฟล์ที่ key นั้นอัปโหลด) หรือผู้ใช้ที่มีสิทธิ์จัดการการนำเข้าทุกชนิดที่ใช้ไฟล์นั้น; การเข้าใช้งานแทนไม่เห็น; downloadUrl ของไฟล์นำเข้าหมดอายุ 60 วินาที — ไม่มีสิทธิ์ = 404DocumentDto
401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (documents:read) — permission_deniedProblemDto
404ไม่พบ (รวมข้อมูลของบริษัทอื่น — ไม่บอกว่ามีอยู่) — not_foundProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto

ตัวอย่าง

curl -sS -X GET "$TMS_BASE_URL/v1/documents/<id>" \
  -H "Authorization: Bearer $TMS_API_KEY"
const { data, error } = await tms.GET('/v1/documents/{id}', {
  params: { path: { id: "…" } },
});
