GET /v1/stops/{id}

scope: trips:read · operationId: Stops_get

สถานะ/เวลาเป็นค่าที่ไล่จาก event แล้ว · จุดที่ถอดออกแล้วยังเปิดได้ (removedAt) · ลำดับ event ทั้งหมด GET /v1/stops/{id}/events · จุดทั้งเที่ยว GET /v1/trips/{id} (stops[])

Parameters

ชื่ออยู่ที่บังคับชนิดคำอธิบาย
idpathใช่string

Responses

สถานะความหมายbody
200StopDto
401ไม่มี/ผิด credential (Bearer JWT, tk_live_… / tk_test_…) — key ถูกเพิกถอน = key_revoked, หมดอายุ = key_expired — unauthorizedProblemDto
403ไม่มีสิทธิ์ (trips:read) — permission_deniedProblemDto
404ไม่พบจุดแวะ (รวมของบริษัทอื่น) — not_foundProblemDto
429rate_limited — เรียกถี่เกินเพดาน (problem+json มี scope: tenant | key | user | endpoint | ip | link และ retryAfter) รอตาม Retry-AfterProblemDto

GET /v1/stops/{id}/events
