# design — ต้นแบบ UI ที่ export จาก Claude Design

> **ต้นแบบนี้เป็นข้อกำหนดด้านหน้าตาและการใช้งาน — ต้องทำตามอย่างเคร่งครัด** (PO สั่ง 10 พ.ย. 2569) · กฎธุรกิจ/ภาษี/สถานะ/สิทธิ์ยังยึด `docs/` → `spec/` · ความต่างที่รู้แล้วอยู่ใน `spec/12-roadmap-open-questions.md` §3

## กติกา: ทำตามต้นแบบอย่างเคร่งครัด

| เรื่อง | ยึดอะไร |
|---|---|
| layout, ลำดับ/ชื่อคอลัมน์และฟิลด์, ข้อความไทย, สี, ฟอนต์, ขนาด, ระยะ, radius, shadow, icon, empty/loading/error, drawer/modal, ขั้นตอนและปุ่ม, พฤติกรรมเมื่อคลิก/กรอง/เลื่อน | **ต้นแบบ** — ใช้ค่าจริงจากไฟล์ ห้ามเดา ห้ามปรับให้สวยขึ้นเอง ห้ามเพิ่ม/ตัด |
| การคำนวณเงิน/ภาษี, ประเภทและเวลาออกเอกสารภาษี, สถานะและ transition, สิทธิ์, validation | **docs → spec** (ต้นแบบมีจุดผิดที่รู้แล้ว เช่น VAT ทั้งก้อนก่อนรอบ 10) — คงหน้าตาต้นแบบ แก้เฉพาะตัวเลข/ข้อความ/เงื่อนไขที่ผิด |
| หน้า/ฟีเจอร์ที่อยู่นอกเฟส 0 (แอปคนขับ, 3D, AI, custom fields, one-platform ฯลฯ) | **PLAN.md** — ยังไม่ทำ แม้ต้นแบบมี |
| ผู้ให้บริการภายนอก (tile แผนที่, CDN) และข้อมูลตัวอย่าง | **ADR / spec** — ไม่ใช้ของในต้นแบบ |
| ต้นแบบไม่มีหน้า/สถานะที่ต้องทำ หรือขัดกับ docs/spec ในจุดที่ยังไม่อยู่ในรายการ | **หยุดและถาม PO** แล้วบันทึกใน `spec/12` §3 |

การตรวจ: PR ที่มี UI แนบภาพเทียบ "ต้นแบบ | ของจริง" ที่ 1440 px (และ 390 px สำหรับหน้า public); QA เปิดต้นแบบเทียบทุกหน้า; ความต่างที่ไม่อยู่ในข้อยกเว้น = defect ระดับ S3

- **ที่มา:** โปรเจกต์ Claude Design "TMS Design System" (`https://claude.ai/design/p/669ed33b-6e77-4850-a71e-065e0bc496e6`) — Share → Export → Project HTML → Project archive
- **export เมื่อ:** 10 พ.ย. 2569 หลังรอบ 19 (หน้าติดตามรถ 3 มิติ) · Claude Design ปิดบริการ 14 ธ.ค. 2569 — ถ้ามีการแก้ต้นแบบหลังวันนี้ต้อง export ใหม่ทับโฟลเดอร์นี้
- **ประวัติแต่ละรอบ:** `research/design-briefs.md`

## เปิดดู

```bash
cd design/prototype && python3 -m http.server 8765 --bind 127.0.0.1
# แล้วเปิด http://127.0.0.1:8765/TMS%20v4.dc.html
```

ต้องเปิดผ่าน http (ไม่ใช่ `file://`) เพราะโหลด `support.js`, `i18n.js`, `plans.js` แบบ relative · ต้องต่ออินเทอร์เน็ต: ฟอนต์จาก Google Fonts, Leaflet/MapLibre จาก unpkg, tile แผนที่จาก tile.openstreetmap.de (ห้ามใช้ใน production — EXE-001), รูปบางรูปจาก Unsplash · ตรวจแล้ว 10 พ.ย.: TMS v4, TMS Print, TMS Driver App เปิดได้จากเครื่อง

## ข้อควรระวัง

- ข้อมูลในต้นแบบเป็นข้อมูลสมมติทั้งหมด (ชื่อบริษัท "ศรีไทยขนส่ง", โดเมน `srithai-tms.co.th`, เบอร์โทร, ทะเบียนรถ) — ห้ามนำไปใช้เป็น seed ที่ดูเหมือนข้อมูลจริงของบริษัทจริง
- โค้ดในต้นแบบไม่ใช่โค้ด production (runtime ของ Claude Design): สร้างใหม่ด้วย React ใน `apps/web` แต่ผลลัพธ์บนจอต้องตรงต้นแบบ — ดึงค่า CSS/ข้อความจากไฟล์ต้นแบบมาเป็น design tokens และ i18n catalog
- พฤติกรรมที่ขัดกับ spec (VAT ทั้งก้อนก่อนรอบ 10, ปุ่มขอยกเว้นน้ำหนักเกิน, เส้นทางตรงในหน้า 3 มิติ ฯลฯ) ดูรายการใน `spec/12` §3 และ `spec/04` §1.1 ข้อ 4
